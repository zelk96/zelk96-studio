# 立ち姿勢の骨盤傾斜の目安

- 一般的な立ち姿勢：RZZ 2°〜6°
- 自然なコントラポスト：RZZ 5°〜10°
- セクシー寄りの立ち姿勢：RZZ 8°〜15°
- かなり誇張したグラビア・モデル立ち：RZZ 15°〜20°前後

15° 超えてくると骨盤だけ見ると映えても、腰・脚・胸郭とのつながりが不自然になりやすい
だから普段使いなら 5〜12°あたりが一番使いやすいゾーン

かなり使いやすい基準だけ置くなら

- 普通立ち：5°前後
- 色気ある立ち：10°前後
- 誇張：15°前後
  この3段階で覚えると楽
  まずこの値を叩き台にして見た目で±2〜5°調整、でかなり回せる
