# Blender学習 Day 8：実寸で部屋を作り、ドアと窓を開ける

4m×3mの部屋を実寸で作り、Booleanでドアと窓を開口。原点を蝶番へ移した開閉、ガラス、室内照明まで仕上げました。

<p class="post-meta">2026.08.20 · 黒暁</p>

## はじめに

Blender学習8日目。Day 7までのデスク制作を終え、今日から新しいファイルで小さな室内空間を作り始めた。

今回はメートル単位で部屋の寸法を決め、床と壁を組み立てたあと、Booleanモディファイアーでドアと窓の開口部を作った。さらに、ドアの原点を蝶番側へ移して実際の扉らしく開閉させ、窓枠・ガラス・マテリアル・室内照明まで仕上げた。

完成したのは、これから家具を配置していくための「部屋の土台」。これまでの机上の小物制作から、空間全体を設計する段階へ移った1日になった。

![Day 8で完成した部屋のブロックアウト]({{ '/images/blender_day08_development_log/Day08_RoomBlockout_Render.png' | relative_url }})

## 今回の目標

- 単位をメートルに設定し、実寸を意識して部屋を作る
- `寸法`を直接入力して床と壁の大きさを決める
- BooleanのDifferenceで壁にドアと窓を開ける
- オブジェクト原点を蝶番へ移し、自然にドアを回転させる
- 窓枠とガラスを作り、透過素材を設定する
- Areaライトで室内を柔らかく照らす
- カッターを残したまま、非破壊で開口部を管理する

## 新しいファイルを実寸のシーンにする

Day 8は `Day08_RoomBlockout.blend` を新規作成し、シーンの単位系をメートル法、長さをメートルに設定した。

最初の床 `Room_Floor` は、立方体の`寸法`へ直接次の値を入力している。

| 軸 | 寸法 |
| --- | --- |
| X | 4.0 m |
| Y | 3.0 m |
| Z | 0.1 m |

床の上面がZ=0になるよう、位置Zは `-0.05 m` とした。最後にスケールを適用し、X・Y・Zをすべて1へ戻した。

![4m×3mの実寸で作った床]({{ '/images/blender_day08_development_log/floor-real-scale.png' | relative_url }})

これまで多用してきた `S` での拡大縮小と、今回の`寸法`入力は、最終的な見た目を同じにできる。ただし意味は少し違う。

- `S`：現在の形に対する倍率を指定する
- `寸法`：完成後の幅・奥行き・高さを直接指定する

実寸を揃えたい建築物では、最終サイズがそのまま読める`寸法`入力が分かりやすい。どちらを使っても、ベベルやBooleanの前には `Ctrl + A` でスケールを適用しておく。

## 床に2枚の壁を立てる

奥の壁 `Wall_Back` は `4.0 × 0.15 × 2.5 m`、左の壁 `Wall_Left` は `0.15 × 3.0 × 2.5 m` で作った。

2枚を床の外周へ合わせ、角が閉じるように配置した。今回は部屋の中を見ながら作業できるよう、手前と右側の壁はまだ置いていない。

![床と奥・左の壁を組み立てた状態]({{ '/images/blender_day08_development_log/two-walls.png' | relative_url }})

小物では多少の数値差が目立たないこともあるが、壁の位置や厚みがずれると角に隙間ができる。部屋づくりでは、寸法だけでなく「中心位置に厚みの半分を足す」という考え方が重要だった。

## Booleanでドアの開口部を作る

ドア用のカッター `Door_Cutter` として、`0.9 × 0.4 × 2.2 m` の立方体を作った。壁を完全に貫通するよう、壁厚よりもY方向を大きくしている。

![奥の壁を貫通させたDoor_Cutter]({{ '/images/blender_day08_development_log/door-cutter.png' | relative_url }})

`Wall_Back` にBooleanモディファイアーを追加し、演算をDifference、対象を `Door_Cutter` にすると、立方体と重なった部分が壁から差し引かれた。

![Booleanで作ったドアの開口部]({{ '/images/blender_day08_development_log/door-boolean.png' | relative_url }})

モディファイアーは適用せず、カッターも削除していない。カッターのビューポート表示とレンダー表示だけをOFFにしたため、あとから大きさや位置を変えて開口部を調整できる。

## ドアの原点を蝶番側へ移す

扉本体 `Door` は `0.85 × 0.04 × 2.05 m` の薄い立方体で作った。

そのまま回転すると中央を軸に回ってしまうため、編集モードで蝶番側の頂点を選択し、次の順で原点を左端へ移した。

1. `Alt + Z` で透過表示にする
2. 蝶番側の頂点をボックス選択する
3. `Shift + S` →「カーソル → 選択物」
4. オブジェクトモードへ戻る
5. 「原点を設定」→「原点を3Dカーソルへ移動」

原点を移動したことで、Z軸回転がドア中央ではなく左端を中心に行われるようになった。ドアノブは内外にUV球を1個ずつ置き、ドアの子に設定して一緒に動かしている。

![蝶番側を軸に開いたドア]({{ '/images/blender_day08_development_log/door-open.png' | relative_url }})

今回はZ軸へ `-70°` 回転させ、少し開いた状態にした。原点は単なる位置表示ではなく、回転や拡大縮小の基準になることを実感できた。

## 170cmの基準物でスケール感を確認する

室内の大きさを目で判断するため、高さ1.7mの赤い直方体 `ScaleReference_170cm` を追加した。

![身長170cmを想定したスケール参照]({{ '/images/blender_day08_development_log/scale-reference.png' | relative_url }})

壁高2.5m、ドア高2.05mと並べると、人が立ったときの余白が分かりやすい。数値だけで作業するより、身近な大きさを持つ仮オブジェクトを置くほうが、空間の違和感を早く見つけられる。

このとき、新規ファイルではビューポートがソリッド表示だったため、マテリアルの赤色が最初は見えなかった。`Z` → `M` でマテリアルプレビューへ切り替えると表示された。Day 1から継続していた机のファイルでは表示モードも保存されていたため、以前はこの切り替えを意識せずに色が見えていた。

## 左の壁に窓を開ける

窓もドアと同じ方法で作った。`Window_Cutter` を左壁へ貫通させ、`Wall_Left` のBoolean Differenceで四角い穴を開けた。

![Booleanで左壁に作った窓の開口部]({{ '/images/blender_day08_development_log/window-opening.png' | relative_url }})

窓枠は、上下左右の4本を別々の立方体で組み立てた。上下は横長、左右は縦長にし、同じグレーのマテリアルを共有している。

![4本の部材で組んだ窓枠]({{ '/images/blender_day08_development_log/window-frame.png' | relative_url }})

中央には薄い立方体 `Window_Glass` を置き、淡い青色、粗さ0.1、IOR 1.45、伝播ウェイト1.0のマテリアルを設定した。

![透過マテリアルを設定した窓ガラス]({{ '/images/blender_day08_development_log/window-glass.png' | relative_url }})

マテリアルプレビューでガラスが緑色に見えたのは、設定したベースカラーそのものではなく、プレビュー用環境の映り込みが強く見えていたため。ガラスは周囲の環境によって印象が大きく変わる素材だと分かった。

## 部屋のマテリアルを整える

部屋全体にも簡単なマテリアルを設定した。

| 対象 | 主な設定 |
| --- | --- |
| 壁 | 暖かいオフホワイト、粗さ0.8 |
| 床 | 暗いブラウン、粗さ0.65 |
| ドア | 暗い赤茶、粗さ0.5 |
| ドアノブ | ダークグレー、メタリック0.8、粗さ0.25 |
| 窓枠 | ニュートラルなグレー |
| ガラス | 淡い青、粗さ0.1、IOR 1.45、伝播1.0 |

![壁・床・ドアへマテリアルを設定した状態]({{ '/images/blender_day08_development_log/materials.png' | relative_url }})

ドアにはベベルモディファイアーを追加し、量0.015m、セグメント3で外周へわずかな丸みを付けた。建築物は直線が多いが、完全に鋭いエッジのままよりも光が拾われ、厚みが分かりやすくなる。

## Areaライトで室内を照らす

デフォルトライトを削除し、天井付近に `Room_Light` を追加した。タイプはArea、パワー600W、形状は正方形、サイズ2m。少し暖かい白色にしている。

![Areaライトで照らしたレンダービューポート]({{ '/images/blender_day08_development_log/area-light.png' | relative_url }})

点光源より広い面から光が出るため、床や壁へ柔らかい影が落ちた。白い壁が光を受けることで、空の部屋でも奥行きが読み取りやすくなった。

## レンダーで見えた灰色の正体

最初のレンダーでは、開いたドアの向こうが大きな灰色の面に見えた。カッターのレンダー表示が残っている可能性を疑ったが、確認すると `Door_Cutter`、`Window_Cutter`、`ScaleReference_170cm` はすべてレンダーOFFだった。

灰色に見えていたのは、ドアの外側に床や壁などの外部ジオメトリがなく、そのままWorld背景が見えていたためだった。窓が暗く見えるのも同じく、外側の景色をまだ作っていないことと、ガラスに暗い環境が映っていることが原因だった。

見た目だけで原因を決めず、アウトライナーのレンダー可視性と、開口部の先に実際のオブジェクトが存在するかを分けて確認する必要がある。

## 今日使った主な操作・機能

| 操作・機能 | 内容 |
| --- | --- |
| 寸法入力 | 完成後の幅・奥行き・高さを実寸で指定する |
| `Ctrl + A` → スケール | 見た目の大きさを保ったままスケールを1へ戻す |
| Boolean / Difference | カッターと重なる部分を壁から差し引く |
| `Alt + Z` | 裏側を含めて頂点を選択できる透過表示 |
| `Shift + S` | 選択頂点へ3Dカーソルを移動する |
| 原点を3Dカーソルへ | ドアの回転中心を蝶番側へ変更する |
| `Ctrl + P` | ドアノブをドアへペアレントする |
| `Z` → `M` | マテリアルプレビューへ切り替える |
| Areaライト | 広い面から柔らかい光と影を作る |
| `Ctrl + Alt + Num 0` | 現在の視点へカメラを合わせる |

## 振り返り

Day 8では、個々の物を作るだけでなく、4m×3mという空間全体の寸法を先に決めてから各パーツを配置した。`S`で見た目を合わせる方法と、`寸法`で完成サイズを直接決める方法の違いも整理できた。

一番大きな学びは、Booleanと原点の活用だった。壁に穴を開ける作業は、メッシュを直接削らなくてもカッターを使って非破壊で管理できる。ドアも、原点を蝶番へ置けば、特別な仕組みを作らなくても実物らしく開閉できる。

また、マテリアルの色が見えない問題、ガラスの予想外の映り込み、ドアの向こうに見える灰色など、表示結果から原因を切り分ける場面も多かった。モデリングだけでなく、ビューポート表示・可視性・World背景まで含めてシーンを見る必要がある。
