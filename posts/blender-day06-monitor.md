# Blender学習 Day 6：面ごとのマテリアルと発光でPCモニターを作る

青く発光するPCモニターを制作し、追加課題ではArrayモディファイアーを使ってフルキーボードまで作りました。

<p class="post-meta">2026.08.18 · 黒暁</p>

## はじめに

Blender学習6日目。

Day 1から作り続けている机まわりのシーンへ、今回はPCモニターを追加した。本体・支柱・台座はシンプルな立方体から作り、画面には1つのオブジェクト内で別マテリアルを割り当て、青く発光するディスプレイとして仕上げた。

モデリングそのものに加えて、既存のマグカップやランプとの縮尺・配置が合わない問題も発生した。最後は指定された数値だけに頼らず、自分の目で全体のバランスを見ながら小物とカメラを調整した。

![Day 6の完成レンダリング]({{ '/images/blender_day06_development_log/Day06_Monitor_Render.png' | relative_url }})

## 今回の目標

- シンプルな16:9風のPCモニターを作る
- インセットで画面とベゼルを作り分ける
- 1つのオブジェクトの面へ別マテリアルを割り当てる
- 放射を使って画面を発光させる
- 本体・支柱・台座を親子関係でまとめる
- 上面表示でオブジェクト同士の干渉を確認する
- 焦点距離と配置を調整してシーン全体を整える
- 追加課題としてArrayモディファイアーでキーボードを作る

## モニター本体の大きさを決める

机の天板中央へ3Dカーソルを合わせ、立方体を追加して `Monitor_Body` と命名した。X方向へ広げ、Y方向へ薄くし、Z方向へ高さを付けて板状にした。

最初に入力した数値では、既存のマグカップよりも低く、小さな板のように見えた。

![周囲と比べて小さかった最初のモニター本体]({{ '/images/blender_day06_development_log/body-scale-check.png' | relative_url }})

机・マグカップ・本は、それぞれ制作時の見た目を優先して作ってきたため、現実のメートル寸法とは一致していない。そこでモニターだけの数値を正解と考えず、マグカップを身近なサイズ基準として比較しながらX・Z方向へ拡大した。

高さを調整した際も、指定値では本体下端が天板へ埋まったため、最終的には目分量で持ち上げた。支柱を入れられる隙間があり、モニターとして自然に見える位置を優先した。

## インセットで画面とベゼルを作る

本体を編集モードへ切り替え、正面の大きな面を選択。`I`キーでインセットし、外周に細い枠を残した。続けて中央面を少し奥へ押し込み、画面とベゼルに段差を付けた。

![インセットと押し込みで作った画面]({{ '/images/blender_day06_development_log/screen-inset.png' | relative_url }})

別の板を前へ重ねるのではなく、1つの立方体の面を分割して画面を作っている。ベベルで丸めた本体の形を維持しつつ、正面だけに必要な構造を追加できた。

## 本体へ黒い樹脂マテリアルを設定する

本体全体には `Monitor_Plastic` を作成した。完全な黒ではなく少し明るさを残したダークグレーにし、粗さを `0.35` 前後、メタリックを `0` に設定した。

![黒い樹脂マテリアルを設定した本体]({{ '/images/blender_day06_development_log/plastic-material.png' | relative_url }})

真っ黒にすると枠のベベルや段差まで潰れて見えやすい。わずかに明るいグレーを使うことで、暗い電子機器らしさを保ちながら形状も読み取れるようにした。

## 中央面だけへ発光マテリアルを割り当てる

編集モードで奥まった中央面だけを選択し、2つ目のマテリアルスロットへ `Monitor_Screen` を追加。「割り当て」を実行して、その面だけを青いディスプレイにした。

設定は暗い青のベースカラー、粗さ `0.25`、青い放射カラー、放射の強さ `1.5` とした。

![中央面だけに割り当てた発光マテリアル]({{ '/images/blender_day06_development_log/screen-emission.png' | relative_url }})

新しいマテリアルを作成するだけでは、選択面には反映されない。今回は「面を選択する」「使用するマテリアルスロットを選ぶ」「割り当てを押す」という手順で、1つのオブジェクト内に樹脂と画面の2種類の質感を持たせた。

## 支柱と台座を作る

細長い立方体から `Monitor_Stand` を作り、モニター本体の下端と天板をつないだ。スケール適用後にベベルを加え、本体と同じ `Monitor_Plastic` を再利用した。

![本体の下へ追加したモニター支柱]({{ '/images/blender_day06_development_log/stand-added.png' | relative_url }})

続いて、横長で薄い立方体から `Monitor_Base` を制作。支柱より強めのベベルを加え、机へ接地する丸みのある台座にした。

![支柱の下へ追加したモニター台座]({{ '/images/blender_day06_development_log/base-added.png' | relative_url }})

最後に台座を親として、本体と支柱をペアレントした。

- `Monitor_Base`（親）
  - `Monitor_Body`（子）
  - `Monitor_Stand`（子）

アウトライナーでは、オレンジ色の逆三角形がオブジェクト、緑色の三角形がその中身であるメッシュデータを表している。メッシュデータ名の `立方体.013` を別オブジェクトと見間違えたが、階層とアイコンを見直して区別できた。

## 上面表示で干渉を確認する

モニター一式を机の奥へ移動し、テンキー `7` の上面表示でランプとの位置関係を確認した。斜めの透視表示では前後関係を読み違えやすいが、上から見ると台座同士が重なっていることが分かった。

ランプは `Lamp_Base` を親としてすでにまとまっていたため、台座だけを選択してX方向へ動かすと、アーム・シェード・電球も一式で移動した。

![上面表示で整理した机上の配置]({{ '/images/blender_day06_development_log/top-view-layout.png' | relative_url }})

また、3Dビュー内で複数オブジェクトを選択するときは `Shift`、アウトライナー上では `Ctrl` を使った。操作する領域によって追加選択のキーが違うことも今回確認できた。

## 初回レンダーで見つかった問題

最初のレンダリングでは、モニター上部が画角から見切れ、マグカップとモニター本体が物理的に交差していた。

![見切れとオブジェクトの干渉が残った初回レンダー]({{ '/images/blender_day06_development_log/first-render-cropped.png' | relative_url }})

モデリング中の自由視点では各パーツを確認できても、最終カメラから見たときに問題が出ることがある。そこでカメラの焦点距離を `40mm` へ変更して画角を広げ、上面表示を使いながら小物の配置を見直した。

マグカップを一方向へ動かすだけでは、今度は本へ埋まってしまった。さらに見比べると、そもそもマグカップがモニターに対して大きすぎることに気付いた。

## 数値を離れ、自分でシーンを整える

最後はマグカップを均等に縮小して天板へ接地させ、モニター・本・ランプ・カップが交差しないよう配置を組み直した。

- 左手前：本
- 左奥：デスクライト
- 中央奥：モニター
- 右手前：マグカップ

モニターを主役として画面内へ収めつつ、小物が左右へ分散する構図になった。青い画面と同系色のマグカップも離して置くことで、色が一か所へ固まらずバランスが取れた。

今回は、教わった数値をそのまま再現するだけでは完成しなかった。周囲のオブジェクトと比較し、「何が大きすぎるか」「どこが重なっているか」「画面内でどう見えるか」を自分で判断して直した結果、最初のレンダーより自然な作業机へ仕上げられた。

## 追加課題：Arrayでキーボードを作る

Day 6本編の保存後、復習課題としてモニター前に置くキーボードを制作した。

最初の条件は、薄い立方体の本体、小さなキーの複製、ベベル、マテリアル、親子関係という既習操作を組み合わせた簡易キーボードだった。まず `Keyboard_Base` とキー1個を作り、モニターとの縮尺を見ながら配置した。

![キーボード本体と最初のキー]({{ '/images/blender_day06_development_log/keyboard-base-first-key.png' | relative_url }})

### 複製からArrayへ切り替える

当初は `Shift + D` でキーを1個ずつ増やす予定だったが、等間隔に大量配置する用途には**Arrayモディファイアー**が適していると判断した。

最初のキーへArrayを追加し、個数を `6`、相対オフセットXを `1.3` 前後に設定。キー同士へ少し隙間を残した横一列を作った。その列を `Shift + D` で複製すると、Arrayの設定を持った行ごと下段へ増やせた。

![Array付きの列を複製して作った上段と下段]({{ '/images/blender_day06_development_log/keyboard-array-rows.png' | relative_url }})

複製した各行のArrayは独立しているため、上から `6・5・4` と個数を減らし、開始位置を少しずつ右へずらした。ミラーモディファイアーが基準点を中心に対称形を作るのに対し、Arrayは一定方向へ同じ間隔で連続配置する機能だと理解できた。

### 簡易案からフルキーボードへ発展

課題では3段とスペースキーだけでも完成だったが、さらに行を増やし、実際のキーボードに近い形へ自主的に発展させた。

- 文字キーの複数行
- ファンクションキー
- スペースキー
- `Shift`、`Enter`、`Backspace`、`Tab`
- 右下のキー群

通常キーはArrayで効率よく並べ、特殊キーは横幅や位置を個別に調整した。オブジェクトも `Keyboard_Row01`、`Keyboard_Space`、`Keyboard_Enter` など、役割が分かる名前へ整理した。

![特殊キーまで追加したフルキーボード]({{ '/images/blender_day06_development_log/keyboard-full-layout.png' | relative_url }})

### 大量オブジェクトの親子付けと修復

すべてのキーを `Keyboard_Base` の子にするため、アウトライナーで `Keyboard_` を検索してまとめて選択した。

ただし、検索前から選択されていた `Monitor_Body` が非表示のまま選択状態を保っており、誤ってキーボードの子へ入ってしまった。`Alt + P` の「親子関係をクリア（トランスフォーム維持）」で見た目を動かさず外し、改めて `Monitor_Base` の子へ戻した。

![キーボードとモニターの親子関係を修正した状態]({{ '/images/blender_day06_development_log/keyboard-parenting-corrected.png' | relative_url }})

検索で表示を絞ることと、実際の選択状態は別である。大量のオブジェクトを操作するときは、処理後にアウトライナーの階層まで確認する必要があると分かった。

### 最新の完成レンダー

キーボードを机の中央へわずかに斜めに配置し、モニター・本・ライト・マグカップと干渉しないことを確認した。最後に椅子の背柱と背もたれを少し高く調整し、椅子のシルエットもより自然にした。

![キーボードと背もたれ調整後の完成レンダー]({{ '/images/blender_day06_development_log/Keyboard_Practice_Render.png' | relative_url }})

簡単な復習課題として始めたが、Array、複製、特殊キーの個別調整、大量オブジェクトの命名と親子付けまで含む制作になった。モニターだけだった机が、実際に使えそうなPCデスクへ一段階発展した。

## 今日使った主な操作・機能

| 操作・機能 | 内容 |
| --- | --- |
| `I` | 選択面をインセットし、外周へ枠を作る |
| `E` | インセットした中央面を奥へ押し込む |
| マテリアルスロット | 1オブジェクトに複数のマテリアルを持たせる |
| 「割り当て」 | 選択した面へ指定マテリアルを適用する |
| 放射 | 画面のような自発光する質感を作る |
| `Ctrl + P` | 本体・支柱・台座を親子関係でまとめる |
| Arrayモディファイアー | 同じキーを一定方向へ等間隔に連続配置する |
| `Shift + D` | Array設定を持った行を複製する |
| `Alt + P` | 親子関係を解除し、誤った階層を修正する |
| `H` / `Alt + H` | 選択物を非表示／再表示する |
| テンキー `7` | 上面からオブジェクト同士の干渉を確認する |
| カメラの焦点距離 | カメラ位置を変えずに画角を調整する |
| `F12` | レンダリングして最終構図を確認する |

## 振り返り

Day 6では、インセットと面ごとのマテリアル割り当てにより、1つの本体へ黒いベゼルと発光する画面を作れた。支柱と台座も加わり、単純な板ではなくPCモニターとして読める形になった。

操作上の小さな発見も多かった。親オブジェクトを `H` で隠しても子は自動では隠れないこと、3Dビューとアウトライナーでは複数選択のキーが異なること、アウトライナー内にはオブジェクトだけでなくメッシュデータやマテリアルも表示されることを確認した。

一番大きかったのは、数値と目分量の使い分けだった。正確な配置や同じ形の再現には数値が便利だが、既存シーンに対する縮尺や最終構図は、実際の見え方を確認して調整する必要がある。今回は問題を自分で発見し、自分なりのスケールと配置へ直して完成させられた。

追加課題では、同じ形を大量に並べる作業を通してArrayの効果を実感した。最初の簡易案で終わらず、特殊キーを追加してフルキーボードまで作り切ったことで、「機能を教わって再現する」だけでなく、「覚えた機能を使って自分で制作範囲を広げる」練習にもなった。

## 次回

次回もこの作業机シーンを引き継ぎ、これまでの基本操作を復習しながら、新しいモデリングや質感表現へ進む予定。
