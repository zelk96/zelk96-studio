# Blenderでハイヒールの足首とつま先を地面へ固定する方法

キャラクターの腰を上下させると、FKで作った脚は身体と一緒に動き、ハイヒールが床から浮いたり滑ったりする。

足首位置だけをIKで固定しても、すねの角度が変わるたびに`Foot`が回転し、つま先側の靴底とヒール先端が揺れる場合がある。

今回は、足首の位置と足の向きを別の制約へ分けて固定した。

## 完成形の構成

左脚の場合は次の構成になる。

```text
IK_Foot_L_Target
├─ lShinのIKが位置を参照
└─ lFootのCopy Rotationが向きを参照
```

右脚も同様に`IK_Foot_R_Target`を使用する。

この構成では、次の二つを同時に固定する。

- IKで足首のワールド位置を維持する
- Copy Rotationでハイヒールの角度を維持する

足首位置と靴の角度が変わらなければ、つま先側の靴底とヒール先端も同じ接地点へ残る。

## 1．IK導入前のファイルから始める

すでに大量のキーやコンストレイントがある状態へ途中からIKを追加すると、足が別の場所へ飛んだり、既存の親子階層と制約が衝突したりする場合がある。

可能ならIK導入前のバックアップを別名保存し、そこから作業する。

最初にFKで脚を調整し、ハイヒールのつま先側の靴底とヒール先端が床へ自然に接している姿勢を作る。

人体のかかとではなく、実際に地面へ触れている靴底とヒール先端を見て判断する。

![ハイヒールを床へ接地させた初期姿勢]({{ '/images/guides/foot-ik/01.png' | relative_url }})

## 2．Footと完全に一致したEmptyを作る

位置だけでなく向きも正確に一致させるため、Emptyへ一時的なCopy Transformsを使用する。

1. オブジェクトモードでEmptyを追加する
2. Emptyへ`Copy Transforms`コンストレイントを追加する
3. ターゲットに女性側アーマチュアを指定する
4. ボーンに`lFoot`を指定する
5. Emptyが`lFoot`と同じ位置・向きへ移動したことを確認する
6. コンストレイントのメニューから「適用」を実行する
7. Emptyを`IK_Foot_L_Target`へ改名する

「適用」後はCopy Transformsコンストレイントが消え、Footと同じワールド位置・回転を持つEmptyだけが残る。

Copy Transformsを適用せずに残すと、後からFootがEmptyを参照したときに循環したり、意図しない動きになる可能性がある。

## 3．ShinへIKを追加する

女性側アーマチュアをポーズモードにし、`lShin`を選択する。

IKコンストレイントを追加し、次のように設定する。

| 項目           | 設定               |
| -------------- | ------------------ |
| ターゲット     | `IK_Foot_L_Target` |
| チェーンの長さ | 2                  |
| ストレッチ     | OFF                |
| 影響           | 1.000              |

チェーン長2にすると、すねと太ももがターゲットまでの位置を解く。身体を上下させても足首位置が残る。

`Foot`ではなく`Shin`へIKを追加するのが重要である。

## 4．FootへCopy Rotationを追加する

次に`lFoot`を選択し、`Copy Rotation`コンストレイントを追加する。

| 項目           | 設定               |
| -------------- | ------------------ |
| ターゲット     | `IK_Foot_L_Target` |
| ターゲット空間 | ワールド空間       |
| オーナー空間   | ワールド空間       |
| ミックス       | 置き換え           |
| 影響           | 1.000              |

EmptyはあらかじめFootと同じ向きになっているため、Copy Rotationを追加しても初期姿勢が変化しない。

これで、`Shin`のIKが足首位置を固定し、`Foot`のCopy Rotationがハイヒールの角度を固定する。

![ShinのIKとFootのCopy Rotationを設定した状態]({{ '/images/guides/foot-ik/02.png' | relative_url }})

## 5．右脚にも同じ設定を行う

右側は次の組み合わせへ置き換える。

- `lFoot` → `rFoot`
- `lShin` → `rShin`
- `IK_Foot_L_Target` → `IK_Foot_R_Target`

左右を設定した後、`hip`を上下させて次の項目を確認する。

- 足首位置が動かない
- つま先側の靴底が床から離れない
- ヒール先端が床へ埋まらない
- 膝が反転しない
- ブーツや脚のメッシュが大きく破綻しない

![身体を動かしてもハイヒールが固定されている状態]({{ '/images/guides/foot-ik/03.png' | relative_url }})

## 失敗例1：Footへ二つ目のIKを追加する

`Shin`へIKを設定した後、`Foot`にもIKを追加すると、足首位置を解く制約が重複する。

特にチェーン長が`0`のままでは、接続されている上位階層まで計算対象になる可能性があり、脚全体が大きく崩れる。

今回の目的では、位置は`Shin`のIK、向きは`Foot`のCopy Rotationへ分ける。

## 失敗例2：FootへChild Ofを途中追加する

`Foot`へChild Ofを追加し、回転軸だけを有効にして同じEmptyへ追従させる方法も試した。

しかし、Footの親であるShinの変形、IK結果、Child Ofの行列計算が重なり、脚が大きく別の位置へ飛んだ。

変形ボーンへChild Ofを後付けせず、向きだけを担当するCopy Rotationを使用する方が扱いやすかった。

## 膝が不安定な場合

深くしゃがんだ姿勢では、IKだけだと膝の向きが反転したり、フレームごとに揺れたりする場合がある。

膝の前方または外側へPole Target用Emptyを置き、ShinのIKへ設定する。Pole Angleは脚が自然な方向を向くまで調整する。

左右の膝には別々のPole Targetを使用する。

## 後からかかとを上げる場合

つま先を支点としてかかとを持ち上げたい場合は、つま先の接地点へ`ToePivot_L`を作る。

`IK_Foot_L_Target`を`ToePivot_L`の子へ「トランスフォームを維持」で親子付けする。`ToePivot_L`を回転すると、つま先位置を中心にFootターゲットが円弧状に移動し、かかとを上げられる。

通常の固定中はToePivotを動かさず、かかとを上げる場面だけ回転へキーフレームを登録する。

## 床自体が動く場合

床が動かないなら、足ターゲットEmptyはワールド空間へ置いたままでよい。

動く床、乗り物、足場などへ固定する場合は、足ターゲットEmptyを対象オブジェクトへChild Ofする。オブジェクトにはボーンがなくても問題ない。

Child Ofを設定した後は「逆行列を設定」を押し、現在位置を維持する。

## 注意点

- IKターゲットは床面ではなく、Footボーンの基準位置と向きへ合わせる
- ハイヒールでは人体のかかとではなく、靴底前方とヒール先端の接地を見る
- 足首の位置とFootの回転を一つのIKへ無理に担当させない
- `Foot`へ二つ目のIKを追加しない
- Emptyに使用したCopy Transformsは位置合わせ後に適用する
- Toeへ既存の回転キーがある場合は、固定中の値を確認する
- 膝が反転する場合はPole Targetを追加する
- IK導入前のバックアップを残す

通常のポーズアセットには、Emptyや追加したコンストレイントまでは含まれない。この足IKを別シーンでも再利用する場合は、IK設定済みのBlendファイルをテンプレートとして保存する。

## まとめ

まず別名保存して、靴が正しく接地しているフレームへ移動する。

1．足ボーンと完全に一致したEmptyを作る

1. オブジェクトモードでEmptyを追加
2. Emptyへ「トランスフォームコピー」コンストレイントを追加
3. ターゲット：Jiuyin Zhu
4. ボーン：lFoot
5. EmptyがlFootと同じ位置・角度へ移動する
6. コンストレイント右上のメニューから「適用」
7. IK_Foot_L_Targetへ改名

「適用」すると、一時的なCopy Transformsを消しつつ、足ボーンと一致したEmptyの位置・角度だけが残る。ここが最重要。

2．脚の位置IK

lShinへIKを追加して、

- ターゲット：IK_Foot_L_Target
- チェーンの長さ：2
- ストレッチ：OFF

にする。これで太ももとすねが動き、足首位置が固定される。

3．足の角度を固定

lFootへ「回転コピー」を追加して、

- ターゲット：IK_Foot_L_Target
- ターゲット空間：ワールド空間
- オーナー空間：ワールド空間
- ミックス：置き換え
- 影響：1.000
