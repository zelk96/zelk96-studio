# Blender学習26日目｜全身ポーズをキーフレームで動かす

今日は、昨日完成させた全身リグを使い、Tポーズからリラックスポーズへ移行して再び元へ戻る短いアニメーションを作った。

全身のポーズ作成、ポーズのコピー、キーフレームの登録、同じ姿勢を一定時間保つ「ホールド」を実践した。途中ではコピー先のポーズや最終フレームのキーが意図と異なる状態になり、タイムライン上のキーを何度も確認しながら修正した。

## Tポーズを最初のキーフレームへ登録

まずタイムラインをフレーム`1`へ移動し、ポーズモードで全ボーンを選択した。

念のため`Alt + G`、`Alt + R`、`Alt + S`で位置・回転・スケールを初期化し、`I`キーから「位置・回転・スケール」を登録した。

![フレーム1へTポーズのキーフレームを登録](/zelk96-studio/images/day26/01.png)

これでアニメーション開始時の基準姿勢ができた。

## フレーム30にリラックスポーズを作成

次にフレーム`30`へ移動し、Tポーズの左右対称な硬さを崩していった。

- `SH_Spine`を少し傾ける
- `SH_Head`を逆方向へわずかに戻す
- 左右の上腕を下げる
- 両前腕の角度に差を付ける
- 片脚を横から見てわずかに曲げる

最初は片方の上腕が水平のまま残ったため、回転方向を修正した。

![片方の腕だけが水平に残った途中状態](/zelk96-studio/images/day26/02.png)

反対方向へ55度回すと両腕が下がり、左右で少し角度の異なる姿勢になった。

![両腕を下げて左右差を付けた上半身](/zelk96-studio/images/day26/03.png)

## 片脚を緩めて棒立ち感を減らす

真横から確認し、片側の太もも・すね・足を少しずつ回転させた。

膝は人体と同じく後ろへ曲がる方向に動かし、足が極端な角度にならないよう足首側も調整した。

![側面から片脚をわずかに曲げた状態](/zelk96-studio/images/day26/04.png)

正面へ戻ると、脚の変化は奥行き方向なので目立ちにくいものの、胴体・頭・両腕にはTポーズとは異なるシルエットができていた。

![完成したリラックスポーズを正面から確認](/zelk96-studio/images/day26/05.png)

全ボーンを選択し、フレーム30へ「位置・回転・スケール」のキーを登録した。

## Tポーズへ戻る往復アニメーションを作成

フレーム1のTポーズをコピーし、当初はフレーム60へ貼り付けてキーを登録した。

これにより、タイムラインを再生すると次の動きが作られた。

```text
1：Tポーズ
↓
30：リラックスポーズ
↓
60：Tポーズ
```

![Tポーズとリラックスポーズを往復する最初の動作](/zelk96-studio/images/day26/06.gif)

ポーズを時間上に保存することで、ボーンを毎フレーム操作しなくても中間の姿勢が自動的に作られることを確認できた。

## 同じポーズを並べて停止時間を作る

フレーム30へ到達した直後に戻り始めると動きがせわしないため、同じリラックスポーズを別のフレームにも置いて停止時間を作ることにした。

最初はフレーム36までの6フレームを停止区間としたが、24fpsでは約0.25秒しかなく効果が分かりにくかった。そのため停止区間をフレーム42まで伸ばし、最終フレームも72へ移動した。

```text
1～30：リラックスポーズへ移行
30～42：同じ姿勢を12フレーム保持
42～72：Tポーズへ戻る
```

![停止時間を12フレームへ延長したタイムライン](/zelk96-studio/images/day26/07.gif)

## キーフレームが意図どおりに動かない

ところが再生してみると、フレーム30から42の間でも身体が動き続けていた。

再生だけでは原因が分かりにくいため、フレーム30・36・42を個別にクリックして姿勢を比較した。その結果、フレーム30はリラックスポーズ、36は移動途中、42はTポーズになっており、停止区間の両端が同じ姿勢ではないことが分かった。

ポーズモードでフレーム30の全身ポーズを改めてコピーし、フレーム42へ貼り付けてキーを上書きした。

このとき、マウスカーソルがタイムライン上にあるとキーフレームのコピーとして処理される可能性がある。今回は3Dビュー上部の「ポーズ」メニューから「ポーズをコピー」「ポーズを貼り付け」を選び、操作対象を明確にした。

修正後はフレーム30と42が完全に同じ姿勢になった。

## 最終フレームのTポーズを復元

停止区間を直した後は、今度はフレーム30から72まで同じ姿勢のままになった。

確認すると、最終フレーム72にもリラックスポーズが入っていた。補間方法を変えても、区間の両端が同じ姿勢なら動きは発生しない。

そこでフレーム1のTポーズをコピーし、フレーム72へ貼り付けて「位置・回転・スケール」を上書きした。全キーフレームの補間は、変化を確認しやすいリニアへ統一した。

最終的な構成は次のようになった。

| フレーム | 姿勢・役割                       |
| -------: | -------------------------------- |
|      `1` | Tポーズ                          |
|     `30` | リラックスポーズ                 |
|     `42` | フレーム30と同じリラックスポーズ |
|     `72` | Tポーズ                          |

![1・30・42・72に整理した最終キーフレーム](/zelk96-studio/images/day26/08.gif)

完成後は、フレーム1から30で腕を下げ、30から42で完全に停止し、42から72で再び腕を上げてTポーズへ戻ることを確認した。

## 今日の振り返り

今日は完成した全身リグへ初めてまとまったポーズを付け、複数ボーンの姿勢をキーフレームとして保存した。

左右の腕を同じ角度にせず、背骨と頭にもわずかな差を付けることで、Tポーズより人間らしいシルエットを作ることができた。一方で、片脚の奥行き方向の変化や全身の重心については、まだ十分に扱えていない。

後半はキーフレームのコピーと移動が複雑になり、どのフレームにどのポーズが保存されているのか分からなくなった。最終的には再生結果だけで判断せず、重要なフレームを一つずつクリックして姿勢を比較することで原因を特定できた。

操作を完全に理解できた感覚はまだないが、ポーズとキーフレーム、同じ姿勢を並べて作る停止時間、区間の両端に異なる姿勢が必要なことを実際の失敗から確認できた。今後も短いアニメーションを繰り返し作りながら慣れていきたい。
