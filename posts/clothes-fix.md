# パンツのメッシュを編集モードで少し外側へ膨らませる方法

![破れたパンツ](/zelk96-studio/images/blender-note/20260916/01.png)

パンツ破れてるから直す。

1. アウトライナーからパンツのオブジェクトを選択
2. Tab → 編集モード
3. 貫通してる腰・股間周辺の頂点を選択
4. Alt + S
5. マウスを少し動かして、パンツを法線方向へ外側に膨らませる
6. 左クリックで確定

![直ったパンツ](/zelk96-studio/images/blender-note/20260916/02.png)

Alt + S は普通の S と違って、各頂点を法線方向へ押し出すから、服を身体から少し浮かせる用途にかなり便利。

今回の画像だと、特にパンツ中央〜左右の腰骨付近だけを選んで Alt + S でほんの少し外へ出せば直る。
全体を膨らませるとパンツがブカブカになるから、貫通部分だけ選ぶのがポイント。
