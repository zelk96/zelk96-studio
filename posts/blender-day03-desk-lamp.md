# Blender学習 Day 3：デスクライトを作り、親子関係と発光を学ぶ

複数パーツを組み合わせてデスクライトを制作。ペアレント、ソリッド化、発光マテリアル、ポイントライトを学びました。

<p class="post-meta">2026.08.15 · 黒暁</p>

## はじめに

Blender学習3日目。

Day 1で作った机と、Day 2で追加したマグカップのシーンを引き継ぎ、今回はデスクライトを制作した。

これまでは立方体や円柱を加工して単体の小物を作ってきたが、今回は台座・支柱・アーム・シェード・電球という複数のパーツを組み合わせる。さらに、パーツを別々に保ったまままとめて動かす「ペアレント」、形に厚みを付ける「ソリッド化」、発光マテリアルとライトの違いも学んだ。

![Day 3の完成レンダリング]({{ '/images/blender_day03_development_log/Day03_DeskLamp_Render.png' | relative_url }})

## 今回の目標

- 複数のパーツからデスクライトを組み立てる
- UV球を加工してランプシェードを作る
- ソリッド化モディファイアーで薄い面に厚みを付ける
- ペアレントを使い、別オブジェクトのまま全体を動かす
- 同じマテリアルを複数パーツへ一括でリンクする
- 発光マテリアルとポイントライトで電球を光らせる

## 円柱を組み合わせて本体を作る

最初に円柱を低くつぶし、デスクライトの台座を作った。編集モードですべてを選択してベベルを加え、自動スムーズシェードを設定すると、角の立った円柱から製品らしい滑らかな円盤になった。

台座の中央には細長い円柱を支柱として追加し、その上へもう1本の円柱を斜めに配置してアームにした。

アームを最初に数値で移動したときは、下端が支柱の上端ではなく中央付近につながってしまった。今回は形同士が自然につながることの方が重要なので、横から確認しながら目分量で位置を修正した。

![台座・支柱・アームを組み立てた状態]({{ '/images/blender_day03_development_log/lamp-arm-assembly.png' | relative_url }})

## UV球からランプシェードを作る

ライトの傘はUV球から作った。球をZ方向へ少し平たくし、透過表示とボックス選択を使って下半分の頂点を削除。上半分だけを残すことで、下向きに開いた半球状のシェードになった。

最初の大きさではアームに対して小さく、接続部のカバーのように見えたため、全体を1.5倍に拡大した。さらに開口部が机を向くようY軸方向へ傾け、アームの先端だけが上部へ少し食い込む位置に調整した。

![UV球の下半分を削除したランプシェード]({{ '/images/blender_day03_development_log/lamp-shade-half.png' | relative_url }})

シェードは面が1枚だけの状態なので、そのままでは縁に厚みがない。そこで「ソリッド化」モディファイアーを追加し、幅を `0.04m` に設定した。形を直接作り直さなくても、元の曲面を保ったまま均一な厚みを付けられた。

![傾きと接続位置を調整したシェード]({{ '/images/blender_day03_development_log/lamp-shade-adjusted.png' | relative_url }})

## 電球を作り、発光させる

シェードの内側へ小さなUV球を追加し、電球として配置した。下側が縁から少し見える大きさにすると、外から見ても光源らしく見える。

電球には `Bulb_Emission` マテリアルを作成し、少し黄みのある白を設定した。放射の強さは `5`。これで電球そのものは明るく見えるようになった。

![シェード内部へ配置した電球]({{ '/images/blender_day03_development_log/lamp-bulb.png' | relative_url }})

ただし、発光マテリアルを設定しただけでは周囲を十分に照らせない。そこで電球と同じ位置にポイントライトを追加し、パワーを `300W`、半径を `0.15m` に設定した。

今回のポイントライトは全方向へ光るため、シェードの向きに関係なく床や机の下にも光が届く。これは仕組みを理解するための最初の一歩として残し、照射方向を限定できるスポットライトは今後試すことにする。

## 「結合」と「ペアレント」の違い

完成したライトを机の上へ移動するため、台座を親、支柱・アーム・シェード・電球・ライトを子としてペアレント設定した。

Day 2のマグカップでは、本体と取っ手を `Ctrl + J` で結合した。今回は `Ctrl + P` のペアレントを使ったことで、両者の違いを実際のモデルで確認できた。

| 操作 | 結合 | ペアレント |
| --- | --- | --- |
| オブジェクト | 1つになる | 別々のまま |
| 全体の移動 | 1つとして動く | 親を動かすと子もついてくる |
| 個別の調整 | 編集モードで選択する | オブジェクトモードのまま可能 |
| 向いている例 | 一体化したマグカップ | 複数部品からなるライト |

マグカップの本体と取っ手は、完成後に一体として扱いたい。一方、ライトは完成後もシェードの角度、電球の位置、ライトの強さなどを個別に調整する可能性がある。そのため、今回は別パーツのまま全体を動かせるペアレントが適していた。

## マテリアルを4パーツへ一括でリンクする

台座・支柱・アーム・シェードには、黒に近いダークグレーの金属マテリアル `Lamp_DarkGray` を設定した。

4つは独立したオブジェクトだが、1つずつ同じ数値を入力する必要はない。対象をすべて選択し、設定済みのシェードを最後にアクティブ選択してから `Ctrl + L` の「マテリアルをリンク」を実行した。

これで4パーツが同じマテリアルを共有し、どれか1つで色や粗さを変更すれば全体へ反映されるようになった。前回も使った操作だが、今回は4パーツへ一括適用したことで、アクティブオブジェクトの設定が他へ渡る仕組みをより明確に理解できた。

![ダークグレーのマテリアルを共有したデスクライト]({{ '/images/blender_day03_development_log/lamp-material.png' | relative_url }})

## 今日使った主な操作・機能

| 操作・機能 | 内容 |
| --- | --- |
| `Ctrl + B` | 選択した辺をベベルする |
| `Alt + Z` | 透過表示を切り替える |
| `B` | ボックス選択を使う |
| `X` | 選択した頂点などを削除する |
| ソリッド化 | 面に均一な厚みを付ける |
| `Ctrl + P` | 親子関係を設定する |
| `Ctrl + L` | マテリアルなどをリンクする |
| 放射 | オブジェクト自体を発光して見せる |
| ポイントライト | 1点から全方向へ光を照射する |
| `F12` | レンダリングする |

## 振り返り

Day 3では、単に形を作るだけでなく、複数パーツをどう管理するか、見た目の発光と実際の照明がどう違うかまで学べた。

特に大きかったのは、結合とペアレントの使い分けを理解できたこと。全部を1つにすればよいわけではなく、後から個別調整したいものは独立性を残した方が扱いやすい。

また、シェードの大きさや傾き、アームとの接続位置は、数値だけでは自然に決まらなかった。視点を回しながら「デスクライトに見える比率」を自分で判断し、何度か直した過程も大切な学習になった。

机だけだったDay 1のシーンに、マグカップ、そして光るデスクライトが加わった。小物を1つずつ増やすことで、単なる練習用モデルから少しずつ場面らしさが生まれてきた。

## 次回

次回は、今回使ったポイントライトと照射方向を限定できるスポットライトの違いを試すか、机の周囲へ新しい小物を追加しながら、さらに別のモデリング操作へ進む予定。
