# Blender実制作 Day34（後編）：補助光とEEVEE設定を調整して完成レンダーを作る

Day34前編では全身ポーズ、中編では冷淡な見下ろし表情を完成させた。

後編では、テストレンダーで見つかった足元の問題を補助光で改善し、EEVEEのサンプル数、最終解像度、PNGの出力設定を決めて完成レンダーを書き出す。

## 最初のレンダーで足元が暗くなった

ポーズと表情を決めた状態でレンダーすると、顔や上半身は見えていたが、黒いロングブーツが暗い壁と床へ溶けていた。

![補助光追加前のテストレンダー]({{ '/images/day34-render/01.jpg' | relative_url }})

ブーツのシルエットが分かりにくく、膝下が大きな黒い塊に見える。作品全体を明るくすれば見えるようになるが、監獄の暗い雰囲気まで失われてしまう。

そこで、足元だけへ弱い補助光を追加することにした。

## ブーツ用のエリアライトを追加する

新しいエリアライトを作成し、`Cinematic_Light_LegFill`と名付けた。

設定は次のとおり。

| 項目     | 設定                 |
| -------- | -------------------- |
| タイプ   | エリア               |
| シェイプ | ディスク             |
| パワー   | 300 W                |
| サイズ   | 1.5 m                |
| 色温度   | 6500 K相当の寒色寄り |

ライトはカメラから見て右前方、膝に近い高さへ配置し、キャラクターの脚へ向けた。

![右前方へ配置したCinematic_Light_LegFill]({{ '/images/day34-render/02.jpg' | relative_url }})

小さく強いライトでは一部だけが白く飛びやすいため、1.5mの面光源にして広い範囲へ柔らかく当てた。

## ブーツの輪郭と光沢が見えるようになった

補助光を追加して再レンダーすると、太ももからつま先までの輪郭が背景から分離した。

![LegFill追加後のテストレンダー]({{ '/images/day34-render/03.jpg' | relative_url }})

黒いまま明暗差が生まれ、レザーの横ジワと縦方向のハイライトも確認できる。明るく塗りつぶしたのではなく、反射によって素材感を見せられた。

さらに、このライトは身体の右側と顔にも弱く回り込み、上半身も少し見やすくなった。顔専用ライトの追加も考えたが、これ以上明るくすると監獄の暗さと冷たい雰囲気が弱くなるため、`LegFill`だけで完成とした。

## EEVEEのレンダーサンプルを上げる

使用しているレンダーエンジンはEEVEEだった。

最初の設定は次のとおり。

- ビューポートサンプル：16
- レンダーサンプル：64

テストレンダーでは壁、床、肌の一部に細かなざらつきが残っていたため、レンダーサンプルだけを`128`へ上げた。ビューポートは操作の軽さを優先し、`16`のままにした。

![EEVEEのサンプリング設定]({{ '/images/day34-render/04.jpg' | relative_url }})

128サンプルでは、壁と床のざらつき、肌の粒状感、ブーツのハイライトが64サンプルより滑らかになった。

1600×900の確認レンダーは約1分14秒、最終の1920×1080レンダーは約1分34秒だった。静止画として十分に待てる時間であり、256サンプルまで上げても改善量は小さいと判断して、最終も128サンプルにした。

## 最終解像度と出力設定

完成画像はフルHDのPNGとして保存した。

| 項目         | 設定                                      |
| ------------ | ----------------------------------------- |
| 解像度       | 1920 × 1080                               |
| スケール     | 100%                                      |
| アスペクト比 | 1:1                                       |
| ファイル形式 | PNG                                       |
| カラー       | RGB                                       |
| 色深度       | 8bit                                      |
| 圧縮         | 15%                                       |
| 保存先       | `//renders/PrisonCell_Cinematic_HERO.png` |

![完成レンダーの出力設定]({{ '/images/day34-render/05.jpg' | relative_url }})

保存先の先頭にある`//`は、現在のBlendファイルから見た相対パスを表す。プロジェクトを別の場所へ移しても、同じ階層の`renders`フォルダへ出力しやすい。

背景を透過しない作品なのでRGBAは不要で、RGBに変更した。PNGの圧縮率はファイルサイズと保存時間に影響するが、JPEGのように画質を劣化させる設定ではない。

## 完成レンダー

設定を保存し、F12で最終レンダーを実行した。

![監獄に立つJiuyin Zhuの完成レンダー]({{ '/images/day34-render/06.jpg' | relative_url }})

顔と表情、帽子、黒い衣装、ブーツの光沢まで確認できる一方、壁と床は暗いまま残った。

キャラクターは画面中央より右に配置し、左手前のベッド、中央奥の椅子、右奥のトイレを残している。背景を大きく見せたことで、自作した独房の閉塞感とキャラクターの存在感を同時に出せた。

Day33までに修正したストランドヘアーと制帽も正常にレンダーされ、ポーズ、表情、背景、ライティングを一枚へまとめることができた。

## 今回の学び

- 黒い衣装は、暗い背景に置くと輪郭と素材感が失われやすい
- 作品全体を明るくするのではなく、必要な場所だけへ補助光を当てる方法がある
- 大きめのエリアライトなら、レザーへ柔らかいハイライトを作れる
- 足元用ライトが顔や身体にも回り込む場合、顔専用ライトが不要になることもある
- EEVEEではレンダーサンプルを上げることで細かなざらつきを抑えられる
- ビューポートとレンダーのサンプル数は、操作性と画質に合わせて分けて設定する
- 128サンプルでも、フルHDの静止画として十分な画質を得られた
- 相対パスを使うと、Blendファイルと出力画像をプロジェクト単位で管理しやすい
- 調整を続けるだけでなく、目的を満たした時点で完成と判断することも重要

## Day34のまとめ

今日は、完成済みキャラクターを監獄へ置くだけの予定から始まり、最終的には次の作業まで進めた。

- キャラクターの配置と接地
- 一枚絵用のカメラ構図
- 女幹部らしい全身ポーズ
- 再利用可能なポーズアセット
- Standard MorphsとFACSの導入
- 見下ろす視線と冷淡な表情
- 表情モーフ値の記録
- 黒いブーツを見せる補助光
- EEVEEのノイズ軽減
- フルHDの完成レンダー

自作した背景へ既存キャラクターを配置し、ポーズ、表情、光、出力まで一通り仕上げられた。単体モデルの修正から一歩進み、複数の要素を組み合わせて一枚の作品として完成させる実制作になった。
