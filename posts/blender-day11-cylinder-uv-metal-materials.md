# Blender学習 Day 11：円柱UVと金属PBRで錆びたゴミ箱を作る

円柱ゴミ箱のシームを試行錯誤し、Metalマップを含む錆鉄PBRとNoise Textureによる古びた真鍮を作りました。

<p class="post-meta">2026.08.23 · 黒暁</p>

## はじめに

Blender学習11日目。Day 10で箱型オブジェクトのUV展開と木材PBRを学んだので、今回は円柱と曲面へ進んだ。

制作したのは、机の横へ置く小さな金属製ゴミ箱。円柱を中空にしてから、外壁・内壁・上端・底面を考えながらシームを設定した。

後半ではMetalマップを含む錆びた鉄のPBR素材を適用し、追加課題として木箱の留め具をプロシージャルな古びた真鍮へ変更した。

![錆びた金属製ゴミ箱と真鍮の留め具を追加したDay 11の室内]({{ '/images/blender_day11_development_log/Day11_FinalRender.webp' | relative_url }})

## 今回の目標

- 円柱を中空にしてゴミ箱を作る
- 円柱と曲面に必要なシームを考える
- UV展開の失敗からシームを修正する
- Diffuse、Roughness、Metal、Normalを使った金属PBRを作る
- Noise Textureで真鍮の光沢ムラ・黒ずみ・細かな腐食を作る
- ノードを「情報を加工して次へ渡す流れ」として捉える

## 円柱を中空にしてゴミ箱を作る

最初に32頂点の円柱を追加し、直径約32cm、高さ約35cmへ調整した。オブジェクト名は `TrashCan_Body`。スケールを適用したあと、幅 `0.01m`・3セグメントのベベルを追加した。

上面を選択して `I` → `0.02` で内側へ縁を作り、内側の面を `E` → `Z` → `-0.30` で下へ押し出した。これで、外側だけでなく内壁と底を持つ容器になった。

![インセットと押し出しで内側を作った円柱ゴミ箱]({{ '/images/blender_day11_development_log/trashcan-hollow.webp' | relative_url }})

最後に自動スムーズを設定。円柱の輪郭を滑らかにしつつ、上端の縁はベベルで光を拾える形にした。

## 最初のUVは細い短冊に分かれた

円筒を開くため、外壁と内壁に縦方向のシーム、底との境界に円周状のシームを入れた。

しかし、縦辺を選ぶときに `Alt + 左クリック` を使ったことで、意図した1本だけでなく複数の縦辺が選択されていた。展開すると側面の各面が切り離され、細い短冊が大量に並ぶUVになった。

![側面が細い短冊へ分割された最初のUV展開]({{ '/images/blender_day11_development_log/uv-short-strips.webp' | relative_url }})

ここで、選択方法を使い分ける必要があると分かった。

| 選びたいもの | 操作 |
| --- | --- |
| 縦方向の辺1本 | 普通の左クリック |
| 円周状の辺ループ | `Alt + 左クリック` |

## 一続きにしすぎると扇形に歪んだ

シームを一度すべてクリアし、縦辺を1本ずつ選び直した。短冊への分裂は解消したものの、今度は外壁・上端・内壁を一続きの面として開こうとしたため、大きな扇形に歪んだ。

![外壁・上端・内壁が一続きになり扇形へ歪んだUV]({{ '/images/blender_day11_development_log/uv-fan-distortion.webp' | relative_url }})

閉じた形を開く切れ目はあっても、形状の変化が大きい部分まで一枚へまとめると無理が出る。そこで、外壁・上端・内壁・2枚の底面をそれぞれ別のUVアイランドとして扱う方針に変えた。

## 形状の境界で分けて展開する

最終的に、次の辺へシームを設定した。

- 外壁と外側底面の境界
- 外壁と上端の境界
- 上端と内壁の境界
- 内壁と内側底面の境界
- 外壁の縦辺1本
- 上端を横切る辺1本
- 内壁の縦辺1本

展開後に「アイランドの大きさを平均化」と、余白 `0.02` の「アイランドを梱包」を実行した。

![外壁・内壁・上端・底面を分けた最終UV]({{ '/images/blender_day11_development_log/uv-final-islands.webp' | relative_url }})

最終結果は、外壁と内壁が長方形、上端が輪、底面が円2枚の合計5アイランド。平面である上端は輪の形を保ったままなので、無理に長方形へ伸ばすより歪みが少ない。

今回の修正から、シームは単に「閉じた形へ切れ目を入れる」だけでなく、形状の役割ごとに面を分ける設計でもあると分かった。

## Metalマップを加えた錆びた鉄のPBR

ゴミ箱にはPoly Havenの[Metal Plate 02](https://polyhaven.com/a/metal_plate_02)を使用した。Day 10の木材ではDiffuse、Roughness、Normalの3種類だったが、今回はMetalを加えた4種類を接続した。

| マップ | 接続先 | 色空間 | 役割 |
| --- | --- | --- | --- |
| Diffuse | ベースカラー | sRGB | 錆や汚れを含む表面の色 |
| Roughness | 粗さ | 非カラー | 光沢のある部分と曇った部分 |
| Metal | メタリック | 非カラー | 金属として反射する場所 |
| Normal GL | ノーマルマップを経由してノーマル | 非カラー | 傷や腐食による細かな凹凸 |

Normal Mapの強さは `0.35` に設定した。画像をつないだだけの段階でも、錆びた色、反射のムラ、表面の傷が組み合わさり、単色マテリアルとは大きく違う質感になった。

![4種類の画像を接続した錆鉄のPBRマテリアル]({{ '/images/blender_day11_development_log/rusted-metal-pbr-nodes.webp' | relative_url }})

UVの縦の切れ目は正面から見ると境界として見えやすかったため、オブジェクトをZ方向へ180度回転し、カメラから見えない裏側へ隠した。シームの位置は展開しやすさだけでなく、完成画面から見えるかどうかも考える必要がある。

## 画像を使わず、古びた真鍮を作る

追加課題では、木箱の留め具に使われていた共有マテリアルを `MAT_Crate_AgedBrass` へ変更した。利用数が「5」だったため、プレート、留め具、ループなど5パーツをまとめて更新できた。

まずはPrincipled BSDFだけで基本の真鍮を作った。

| 項目 | 値 |
| --- | --- |
| ベースカラー | `#8C6424` |
| メタリック | `1.000` |
| 粗さ | `0.380` |
| IOR | `1.500` |

ここからNoise Textureを使い、均一だった表面へ3種類の変化を追加した。

## ノードは「情報を加工して渡す」流れ

現時点では、指示どおりにノードを接続することはできても、それぞれの意味はまだ完全には理解できていない。

そこで今回の接続を、左から右へ情報を渡す流れとして整理した。

### 1. 光沢ムラを作る

`Noise Texture → Map Range → Roughness`

Noise Textureが場所ごとに0〜1のランダムな値を作る。そのまま粗さへ入れると、完全な鏡面から完全にざらついた場所まで差が強く出すぎる。

そこでMap Rangeを挟み、入力の `0〜1` を出力の `0.24〜0.58` へ変換した。これにより、どの場所も金属らしい範囲に保ちながら、反射だけを不均一にできた。

途中で「最小から・最大から」と「最小へ・最大へ」を逆に設定し、斑点が極端に出た。値の意味を確認して修正すると、色はほぼ変えず、見る角度によって光沢が揺らぐ状態になった。

### 2. 黒ずみを作る

`Noise Texture → Color Ramp → Base Color`

同じNoiseの値をColor Rampにも分岐させた。Color Rampでは、暗い茶色 `#221407` と真鍮色 `#8C6424` を割り当てた。

同じランダム情報でも、Roughnessへ渡せば光沢ムラになり、Base Colorへ渡せば色ムラになる。ノードの出力は一つの用途に限らず、複数の入力へ分岐して再利用できる。

### 3. 細かな腐食を作る

`Noise Texture → Bump → Normal`

黒ずみとは別に、スケール `35` の細かなNoiseを追加した。Bumpの強さは `0.10`、距離は `0.003`。大きな凹凸ではなく、表面に細かな腐食があるように光の当たり方だけを変化させた。

![2種類のNoiseで黒ずみ・粗さ・微細な凹凸を作った真鍮マテリアル]({{ '/images/blender_day11_development_log/aged-brass-procedural-nodes.webp' | relative_url }})

今回のノード構成をまとめると、次のようになる。

| 元になる情報 | 加工するノード | 接続先 | 見た目への効果 |
| --- | --- | --- | --- |
| 大きなNoise | Map Range | Roughness | 光沢のムラ |
| 大きなNoise | Color Ramp | Base Color | 真鍮の黒ずみ |
| 細かなNoise | Bump | Normal | 微細な腐食 |

## 今日使った主な操作・機能

| 操作・機能 | 内容 |
| --- | --- |
| `I` | 上面をインセットして縁を作る |
| `E` → `Z` | 内側の面を押し下げて容器にする |
| シームをクリア | 失敗した切れ目を一度すべて解除する |
| 普通の左クリック | 縦辺を1本だけ選択する |
| `Alt + 左クリック` | 円周状の辺ループを選択する |
| アイランドの大きさを平均化 | 面積に対するテクスチャ密度を揃える |
| アイランドを梱包 | UVを画像内へ配置する |
| Metal Map | 金属として反射する場所を指定する |
| Noise Texture | 場所ごとにランダムな値を作る |
| Map Range | 入力値を使いたい範囲へ変換する |
| Color Ramp | 数値を色へ対応させる |
| Bump | 高さ情報から疑似的な凹凸を作る |

## 振り返り

Day 11では、箱型より複雑な円柱のUV展開へ進んだ。短冊状のUVと扇形に歪んだUVを経て、最後は形状の境界ごとに5つのアイランドへ分割できた。

失敗した展開も、どのシームが不足しているか、どの面を一緒にしすぎたかを考える材料になった。完成形だけを見るより、シームとUVの関係を強く意識できたと思う。

マテリアルでは、画像を接続する金属PBRと、Noise Textureから作るプロシージャルな真鍮を体験した。まだノードの意味を自力で組み立てられる段階ではないが、「左のノードが情報を作り、途中で加工し、Principled BSDFの各入力へ渡す」という全体像は見え始めた。

## 次回

ノードをただ再現するだけでなく、NoiseのScale、Map Rangeの出力範囲、Color Rampの位置などを自分で変え、どの値が見た目のどこへ影響するか確認する。

そのうえで、金属以外の素材にも同じ考え方を応用し、ノードを少しずつ読めるようにしていく。
