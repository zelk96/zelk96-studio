# Blenderで腕をIK化し、手を別モデルへ固定する方法

キャラクターの身体を動かしたとき、相手の身体へ置いた手まで一緒に動いて離れてしまう。この位置ずれを防ぐため、手首位置へIKターゲットを作り、相手モデルへ追従させる方法を記録する。

今回使用したのは、DiffeomorphicでBlenderへ読み込んだGenesis 9同士である。

## 完成形の構成

```text
男性モデルの接触面を動かすボーン
└─ Child Ofで手首ターゲットEmptyが追従
   └─ 女性側ForearmのIKがEmptyを参照
```

左右それぞれにターゲットを作成する。

```text
IK_Hand_L_Target
IK_Hand_R_Target
```

## 1．FKで手を接触位置へ置く

最初にFKで腕、前腕、手首、指を調整し、手のひらを相手モデルへ自然に接触させる。

IKを付けてから接触位置を探すより、完成させたい姿勢を先に作り、その位置へターゲットを追加する方が分かりやすい。

この時点のBlendファイルは、IK導入前のバックアップとして別名保存しておく。

![FKで手を接触位置へ置いた状態]({{ '/images/guides/arm-ik/01.png' | relative_url }})

## 2．手首位置へEmptyを作る

ポーズモードで手首の基準になるボーンを選択し、`Shift + S → カーソル → 選択物`で3Dカーソルを移動する。

オブジェクトモードへ戻り、3Dカーソル位置へEmptyを追加する。

左右のEmptyを次のように命名する。

```text
IK_Hand_L_Target
IK_Hand_R_Target
```

Emptyは手のひら中央ではなく、腕IKの終点になる手首の回転軸へ置く。位置がずれていると、IKを有効にした瞬間に腕が引っ張られる。

## 3．Emptyを相手モデルへ追従させる

相手モデルが動いたときも手を同じ場所へ残すには、Emptyを相手側のアーマチュアまたはボーンへ追従させる。

手首ターゲットEmptyへ`Child Of`コンストレイントを追加する。

| 項目                 | 設定                       |
| -------------------- | -------------------------- |
| ターゲット           | 相手モデルのアーマチュア   |
| ボーン               | 接触面を実際に動かすボーン |
| 位置・回転・スケール | 必要な項目を有効           |
| 影響                 | 1.000                      |

設定後に「逆行列を設定」を押し、現在のEmpty位置を維持する。

### 追従先ボーンの選び方

ボーン名だけで判断せず、手が触れている表面を実際に動かすボーンを選ぶ。

- 骨盤周辺：`pelvis`
- 下腹部：`spine1`付近
- 胸部：`spine2`以降
- 太もも：`lThigh`または`rThigh`

DAZ Studio側の`abdomenLower`や`chestLower`が、Blenderでも同じ名前になっているとは限らない。

候補ボーンをポーズモードで少し動かし、手を置いている表面が一緒に動くか確認するのが確実である。確認後は操作を元に戻す。

## 4．前腕へIKを追加する

女性側アーマチュアをポーズモードにし、左腕なら`lForearm`、右腕なら`rForearm`を選択する。

ボーンコンストレイントからIKを追加し、次のように設定する。

| 項目           | 設定                       |
| -------------- | -------------------------- |
| ターゲット     | 対応する`IK_Hand_*_Target` |
| チェーンの長さ | 2                          |
| ストレッチ     | OFF                        |
| 影響           | 1.000                      |

チェーン長を2にすると、前腕と上腕がIK計算の対象になる。肩まで大きく巻き込みたくない場合に扱いやすい。

IKターゲットがEmptyの場合、ターゲット欄にはEmptyを直接指定する。Emptyにはボーンがないため、ボーン名を設定する必要はない。

![前腕へIKを設定した状態]({{ '/images/guides/arm-ik/02.png' | relative_url }})

## 5．身体を動かして確認する

`hip`や背骨を動かし、身体を上下または前後へ移動する。

成功していれば、手首はターゲット位置へ残り、肘と肩が追従して角度を変える。相手側が動いた場合も、Child Ofで追従しているEmptyと一緒に手が移動する。

![身体を動かしても手首が残っている状態]({{ '/images/guides/arm-ik/03.png' | relative_url }})

## 肘の向きが不安定な場合

腕が反転したり、肘が意図しない方向へ曲がったりする場合は、肘の後方へPole Target用Emptyを追加する。

IKコンストレイントのPole TargetへそのEmptyを設定し、Pole Angleを調整する。左右の肘へ別々のPole Targetを用意すると制御しやすい。

Pole Targetを置く位置は、肘を曲げたい方向の延長線上を基準にする。

## 床や壁へ手を固定する場合

床や壁のようにボーンがないオブジェクトへ固定する場合も、考え方は同じである。

- 固定先が動かない：Emptyをワールド空間へ置いたままにする
- 固定先が動く：EmptyをFloorやWallオブジェクトへChild Ofする

固定先に必ずボーンが必要なわけではない。動かない場所なら、ワールド空間にあるEmpty自体が固定点になる。

## アニメーションで使う場合

手を固定している間は、手首ターゲットEmptyを動かさず、`hip`、背骨、肩などを動かす。

途中で手を離す場合は、次の方法が使える。

- IKコンストレイントの影響へキーフレームを登録する
- IKターゲットEmpty自体をアニメーションさせる
- IKからFKへ切り替えるための中間姿勢を作る

影響を急に`1`から`0`へ変えると手が飛ぶ場合があるため、切り替え前後の姿勢を確認する。

## 注意点

- IK追加前のファイルをバックアップする
- 手を置き終わってからターゲットを作る
- Emptyは手首の回転軸へ置く
- IKは手ボーンではなく前腕へ追加する
- チェーン長2で前腕と上腕を解く
- ストレッチを切り、不自然に腕が伸びるのを防ぐ
- 追従先はボーン名ではなく、接触面の動きで判断する
- 肘が反転する場合はPole Targetを追加する

通常のポーズアセットには、追加したEmptyやIKコンストレイントまで含まれない。この構成を再利用する場合は、Emptyとコンストレイントを含むIK設定済みBlendファイルをテンプレートとして保存する。

## まとめ

1. 念のためファイルを\_preIKなどで別名保存
2. 左手が正しく接触しているフレームへ移動
3. 女性側をポーズモードにして、左手ボーンを選択
4. Shift+S → カーソルを選択物へ
5. オブジェクトモードへ戻る
6. Shift+A → エンプティ → 十字
7. 名前をIK_Hand_L_Targetにする

次に、このエンプティを男性側へ連動させる。

1. エンプティの「オブジェクトコンストレイント」を開く
2. 子（Child Of）を追加
3. ターゲット：男性側のGenesis 9アーマチュア
4. ボーン：手が触れている場所に近いabdomenLowerやchestLower
5. 逆行列を設定
6. 影響を1.0

そして女性の腕をIK化する。

1. 女性側アーマチュアをポーズモード
2. 左の前腕ボーンl_forearmを選択
3. 「ボーンコンストレイント」からインバースキネマティクス（IK）を追加
4. ターゲットをIK_Hand_L_Targetにする
5. チェーンの長さを2
