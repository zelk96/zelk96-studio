# 腕ポーズ作成の基礎まとめ

まず結論から言うと、腕は「上腕だけ回す」じゃなくて

胸郭 → 鎖骨/肩 → 上腕 → 前腕 → 手首

の順で見るのが基本。

例えば腕を左右に開くポーズなら、上腕を上げたぶんだけ肩も少し持ち上がる・外へ開くのが自然。腕だけ上げて肩が完全固定だと、脇が詰まったり肩関節が埋まった感じになりやすい。

# 基礎として覚えておくといいのはこれ

- 腕を横に上げる

→ 上腕だけじゃなく、肩/鎖骨も少し上がる

- 腕を前に出す

→ 肩も前に出る

- 腕を後ろに引く

→ 肩も後ろに引く

- 手を腰に置く

→ 肩は少し下がる/後ろに引けることが多い

- 肘の向き

→ 上腕のねじりで決まる。ここが変だと前腕だけ直しても不自然

- 手首

→ 最後の仕上げ。手首だけでポーズを作らない

DAZリグなら、ざっくり3ブロックで考えると分かりやすい。

1. shoulder / collar系
   肩帯の位置調整

2. upperarm
   腕全体の向きと肘の方向

3. forearm + hand
   肘の曲げと手先の仕上げ

で、順番は

> 肩を決める → 上腕 → 肘 → 手首

が基本

# 数値の叩き台

たとえば自然な「腕を軽く横に開く」なら

- shoulder：上方向に 2〜5° 程度
- upperarm：必要な角度まで外転
- upperarm twist：肘が自然な方向を向く程度
- forearm：軽く 5〜15° 曲げる
- hand：ごく軽く反らす/傾ける

くらいから始めるといい。

逆にセクシー寄りなら、完全な左右対称は避けて

- 片肩を少し上げる
- 片肘だけ曲げる
- 片手を腰
- もう片方は脱力

みたいに左右差を作ると一気にそれっぽくなる。

**「どの関節が主役で、どこが追従するか」**を決めればいい。

- 脚：支持足 → hip → pelvis → chest → neck
- 腕：chest → shoulder → upperarm → forearm → hand

これだけ覚えとけば、かなり事故減ると思う。
