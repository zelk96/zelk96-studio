# Blender学習 Day 4：本を重ね、立体的な金文字タイトルを作る

2種類のハードカバー本を制作し、マテリアル共有と単独化、立体テキスト、親子関係を実践しました。

<p class="post-meta">2026.08.16 · 黒暁</p>

## はじめに

Blender学習4日目。

Day 1の机、Day 2のマグカップ、Day 3のデスクライトを引き継ぎ、今回は机の上に2冊の本を追加した。

単純な直方体を置くだけではなく、ページ・表紙・背表紙を別パーツとして作り、1冊のハードカバーへ仕上げた。さらに複製した本の比率や色を変えて小説風の2冊目を作り、表紙にはテキストオブジェクトを使った立体的な金文字タイトルも配置した。

![Day 4の完成レンダリング]({{ '/images/blender_day04_development_log/Day04_Books_Render.png' | relative_url }})

## 今回の目標

- ページ・表紙・背表紙からハードカバー本を作る
- 複数オブジェクトを同時に編集してベベルを付ける
- 作成済みマテリアルを再利用する
- 共有マテリアルを単独ユーザー化して色違いを作る
- テキストオブジェクトへ厚みと金属感を加える
- 本とタイトルをペアレントし、一緒に動かせるようにする
- 机上の小物が見やすいカメラ構図へ調整する

## 1冊目：深緑のハードカバーを作る

最初に立方体を薄い直方体へ変形し、ページ部分を作った。初期状態では机に対して本が大きすぎたため、全体を60%へ縮小。真上視点からマグカップとライトの間隔を確認し、天板内に収まる位置へ移動した。

ページを複製し、X・Y方向へ少しだけ広げ、Z方向へ薄くすることで上表紙を作成。同じ表紙をもう一度複製して下へ移動し、ページを上下から挟む構造にした。

![ページを上下の表紙で挟んだ状態]({{ '/images/blender_day04_development_log/book-cover-structure.png' | relative_url }})

縮小後は下表紙と天板の間にわずかな隙間が残っていたため、3パーツを同時に選択してZ方向へ下げ、机へきちんと接地させた。形が合っていても、接地していなければ浮いて見えることを改めて確認できた。

## 複数オブジェクトを同時にベベルする

上下の表紙とページを選択したまま編集モードへ入り、3つを同時にベベルした。幅は `0.02m`、セグメントは `3`。本らしい形を保ちながら、縁へ控えめな丸みを付けた。

複数のオブジェクトを選択した状態でも、まとめて編集モードへ入り、同じ加工を一度に適用できる。独立性を残したまま共通の形状調整を行いたい場合に便利だった。

## 表紙と紙のマテリアル

表紙には深緑の `Book_Cover_Green`、ページには少し黄みのある `Book_Pages_Cream` を作成した。紙は光沢を抑えるため、粗さを `0.75` に設定した。

下表紙には、上表紙で作ったマテリアルをリンクして共有した。また、背表紙にもマテリアル一覧から同じ `Book_Cover_Green` を選択した。

一度作成したマテリアルはファイル内に保存され、一覧から再利用できる。マテリアル名の横に表示される数字は、そのマテリアルを共有しているオブジェクト数だということも確認した。

![深緑のマテリアルを設定した上表紙]({{ '/images/blender_day04_development_log/book-cover-material.png' | relative_url }})

最後に表紙・ページ・背表紙の4パーツを `Ctrl + J` で結合し、見た目と複数のマテリアルスロットを保ったまま、1冊の `Book01_Hardcover` にまとめた。

![表紙・ページ・背表紙を結合したハードカバー本]({{ '/images/blender_day04_development_log/hardcover-complete.png' | relative_url }})

## 2冊目：比率と色を変えて小説風にする

完成した1冊目を複製し、横幅を縮めて奥行きを少し伸ばした。さらにZ軸へ `-6°` 回転させ、下の本と少しずらして重ねた。1冊目が横長の画集・絵本風だったのに対し、2冊目は縦長の小説らしい比率になった。

複製直後は2冊が同じ緑のマテリアルを共有している。このまま色を変更すると両方へ反映されるため、利用数の数字をクリックしてマテリアルを単独ユーザー化した。コピーしたマテリアルを `Book_Cover_Red` に変更し、上の本だけを暗い赤色にできた。

本を重ねた直後にはわずかな隙間があったため、上の本をZ方向へ微調整して下の本へ接地させた。

![緑の画集風ハードカバーと赤い小説風ハードカバー]({{ '/images/blender_day04_development_log/two-books-color-variation.png' | relative_url }})

## テキストオブジェクトで金文字を作る

赤い本の中心へ3Dカーソルを移動し、テキストオブジェクトを追加した。初期文字を `NIGHT` に変更し、水平配置を中央に設定。本と同じくZ軸へ `-6°` 回転させ、表紙の向きへ揃えた。

文字データのジオメトリ設定では、押し出しを `0.02m`、ベベル深度を `0.005m`、解像度を `2` にした。文字に厚みと丸みが加わり、平面印刷ではなく箔押しのような立体感が生まれた。

![NIGHTの文字へ押し出しとベベルを設定]({{ '/images/blender_day04_development_log/title-geometry.png' | relative_url }})

マテリアル `Book_Title_Gold` を作成し、黄土色寄りのベースカラー、メタリック `0.8`、粗さ `0.3` を設定。赤い表紙の上で光を反射する金文字に仕上げた。

## 親子関係とアクティブオブジェクト

タイトルは後から文字を編集できるよう、本とは結合せずペアレントした。

作業中、一度は親子関係が逆になり、タイトルが親、本が子になってしまった。アウトライナーの階層を確認して解除し、最終的に次の構造へ修正した。

- `Book02_Novel`（親）
  - `Book02_Title`（子）

選択順だけを暗記するのではなく、親にしたいオブジェクトがアクティブになっているか、設定後のアウトライナーが意図した階層になっているかを確認する方が確実だった。今回のアウトライナー操作では、先に選んだ本がアクティブなまま親になったため、オレンジ色の表示と階層を見て判断した。

また、タイトルは選択中だけ見え、選択を外すと消える状態になった。これは文字自体ではなく、表紙越しに選択アウトラインだけが見えていたため。文字をZ方向へ少し上げ、表紙の上へ出すことで解決した。

![親子関係を設定し、表紙中央へ戻したタイトル]({{ '/images/blender_day04_development_log/title-parented-top-view.png' | relative_url }})

## カメラ構図と最終レンダリング

本を追加したことで机上の情報量が増えたため、カメラも調整した。机と4本脚を残しながら、2冊の本・マグカップ・デスクライトが見やすくなる斜め上の構図に変更した。

![机と小物が収まるように調整したカメラ構図]({{ '/images/blender_day04_development_log/camera-composition.png' | relative_url }})

完成レンダリングでは、深緑と赤の本、生成り色のページ、金色のタイトルがそれぞれ判別できる。Day 1から小物を追加してきた机が、少しずつ生活感のある場面になってきた。

## 今日使った主な操作・機能

| 操作・機能 | 内容 |
| --- | --- |
| `Shift + D` | オブジェクトを複製する |
| `Ctrl + A` → スケール | 現在の大きさを基準値として適用する |
| 複数オブジェクト編集 | 独立した複数メッシュを同時に加工する |
| `Ctrl + B` | 選択した辺をベベルする |
| `Ctrl + L` | アクティブ側のマテリアルなどをリンクする |
| `Ctrl + J` | 複数オブジェクトを1つに結合する |
| マテリアルの単独ユーザー化 | 共有マテリアルのコピーを作る |
| テキストオブジェクト | 編集可能な立体文字を作る |
| 押し出し・ベベル | テキストへ厚みと丸みを付ける |
| `Ctrl + P` | 親子関係を設定する |
| `Alt + P` | 親子関係を解除する |
| `Ctrl + Alt + テンキー0` | 現在の視点へカメラを合わせる |
| `F12` | レンダリングする |

## 振り返り

Day 4では、直方体を組み合わせる基本的なモデリングから始まり、マテリアル共有、単独ユーザー化、テキストの立体化、親子関係まで幅広く扱った。

特に印象に残ったのは、「見た目は合っていそうでも実際には浮いている」「選択中のアウトラインだけが見えている」「親子関係が意図と逆になっている」といった細かな違和感を、視点やアウトライナーを確認しながら修正したことだった。

また、既に覚えたスケール適用や複製、移動、ベベルなどは、以前より迷わず使えるようになってきた。新しい操作だけでなく、過去に学んだ操作を組み合わせて1つの小物を完成させる段階へ進めている。

次回もこれまでのシーンを引き継ぎ、新しい小物やモデリング方法を追加しながら、机まわりの空間を少しずつ発展させる予定。
