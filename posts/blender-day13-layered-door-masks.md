# Blender学習 Day 13：マスクを重ね、塗装剥がれと錆のドアを作る

NoiseとColor Rampから作った白黒マスクを共有・乗算し、赤い塗装、露出金属、錆を一つのドアへ重ねました。

<p class="post-meta">2026.08.25 · 黒暁</p>

## はじめに

Blender学習13日目。Day 12ではNoise Textureの数値をColor Rampで色へ変え、Map RangeやBumpへ分岐させた。今回はその白黒情報を、2つの素材を切り替える「マスク」として使う。

題材は部屋の赤いドア。赤い塗装、剥がれて露出した金属、さらに一部へ発生した錆という3段階の素材を、画像を使わず一つのPrincipled BSDFへまとめた。

![塗装剥がれと錆を追加したDay 13のドア]({{ '/images/blender_day13_development_log/Day13_FinalRender.webp' | relative_url }})

## 今回の目標

- 白黒マスクを「どちらの素材を出すか」という係数として読む
- 同じマスクを色・メタリック・粗さ・凹凸へ共有する
- Mixノードで塗装と露出金属を切り替える
- Mappingで模様の縦横比を整える
- 2枚のマスクをMultiplyで掛け合わせ、剥がれの中だけに錆を出す
- 複雑なノードを暗記せず、役割ごとのまとまりとして読む

## まずは白黒マスクを作る【復習】

最初の構成はDay 12の復習。

`Texture Coordinate（Generated） → Noise Texture → Color Ramp`

Noise Textureは座標ごとに0〜1の値を作り、Color Rampはその値を白黒へ変換する。Principled BSDFへ直接つないで確認すると、白い場所と黒い場所がドア表面に現れた。

![NoiseとColor Rampで作った白黒マスク]({{ '/images/blender_day13_development_log/noise-mask-preview.webp' | relative_url }})

今回の理解を言葉にすると、次のようになる。

| ノード | 役割 |
| --- | --- |
| Texture Coordinate | 表面上の位置情報を出す |
| Noise Texture | 位置ごとに0〜1の不規則な値を作る |
| Color Ramp | 0〜1の分布を、使いやすい白黒マスクへ整える |
| Principled BSDF | 入力された色・金属度・粗さ・法線をまとめて表面を描く |

「Color Rampが黒白を表示する」というより、入力値へ任意の色を割り当てるノードであり、今回はマスクとして使うため黒白にしている。

## Mix Colorで赤い塗装と金属を切り替える

Color Rampの出力をMix ColorのFactorへ接続し、Aを赤、Bを黄色にして動作を確認した。

![赤と黄色でマスクの切り替えを確認]({{ '/images/blender_day13_development_log/mix-debug-colors.webp' | relative_url }})

MixのFactorでは、黒 `0` に近い場所ほどA、白 `1` に近い場所ほどBが選ばれる。黄色は完成色ではなく、どこがBになるかを見分けるデバッグ用だった。

Color Rampの黒を `0.58`、白を `0.65` 付近まで右へ移動し、白い面積を減らした。これにより、赤い塗装が大部分を占め、ところどころだけ下地が露出する分布になった。

デバッグ後、Bを露出金属の灰色 `#555A5E` へ変更した。

## 1枚のマスクを複数の性質へ共有する

塗装剥がれは色だけの変化ではない。露出した場所は金属として反射し、塗装とは粗さが異なり、境界にはわずかな段差がある。

そこで同じColor Rampのマスクを4方向へ分岐した。

| 接続先 | 黒側：塗装 | 白側：露出金属 |
| --- | --- | --- |
| Base Color | 赤 | 灰色 |
| Metallic | `0.00` | `0.85` |
| Roughness | `0.35` | `0.50` |
| Bump | 塗装面 | 剥がれて少し凹んだ面 |

色用はMix Color、数値用はFloatのMixを使った。BumpはInvertを有効にし、Strength `0.25`、Distance `0.01`。同じ白黒情報を共有するため、灰色になった場所だけが同時に金属らしく反射し、粗さと段差も一致する。

この段階で重要だったのは、ノードの本数ではなく「マスクが一枚あり、その結果を4つの性質が見ている」という構造だった。

## Mappingで縦に伸びた模様を直す

Generated座標をそのまま使うと、縦長のドアではNoiseも縦方向へ引き伸ばされ、剥がれが筋状に見えた。

Texture CoordinateとNoiseの間へMappingを追加し、Scaleを `X 1 / Y 1 / Z 3` に設定。縦方向の座標を3倍の密度で読むことで、模様の縦横比が自然になった。

![Mappingで形を整えた塗装剥がれとノード構成]({{ '/images/blender_day13_development_log/mapping-and-layer-mask.webp' | relative_url }})

NoiseのScaleは模様全体の細かさ、Mappingの各軸は方向ごとの伸び方を調整する。似た操作に見えても担当が違う。

## 剥がれの中だけに錆を出す

次は第三の素材である錆を追加した。錆はドア全体ではなく、塗装が剥がれて金属が露出した場所の一部だけに出したい。

そこで、同じMappingから2つ目のNoiseを作った。

| 設定 | 値 |
| --- | --- |
| Noise Scale | `20` |
| Detail | `3` |
| Roughness | `0.65` |
| Color Ramp | 黒 `0.52` / 白 `0.60` |

この細かな白黒を「錆の候補」とし、MathのMultiplyで塗装剥がれマスクと掛け合わせた。

`剥がれマスク × 錆候補マスク = 実際の錆マスク`

掛け算では、どちらかが黒 `0` なら結果も0になる。両方が白い場所だけが1になるため、塗装面へ錆がはみ出さない。

![2枚のマスクをMultiplyし、剥がれの中だけへ錆を限定]({{ '/images/blender_day13_development_log/rust-mask-multiply.webp' | relative_url }})

## 錆の色・金属度・粗さを上書きする

Multiplyの結果を使い、既に完成していた「赤い塗装＋露出金属」の上へ錆を重ねた。

| 性質 | 既存結果 | 錆部分 |
| --- | --- | --- |
| Base Color | 赤または灰色 | 茶褐色 `#8A2F0E` |
| Metallic | `0.00` または `0.85` | `0.00` |
| Roughness | `0.35` または `0.50` | `0.85` |

錆は酸化物なので金属度を0へ下げ、粗さを上げて乾いた反射にした。新しいMixは前段の結果をAへ受け取り、錆マスクが白い場所だけBで上書きする。

最終的な構造は次の3層になった。

1. 赤い塗装を基本にする
2. 剥がれマスクで露出金属へ切り替える
3. 剥がれマスクと錆候補を掛け、該当部分だけ錆へ上書きする

## 複雑なノードをどう読むか

完成時のノードはかなり複雑になり、何も見ずに同じものを組み直すのは難しいと感じた。ただ、すべてを暗記する必要はない。

今回の到達点は、次の単位を見分けられること。

- Noise：不規則な数値を作る
- Color Ramp：数値の分布をマスクへ整える
- Mix：マスクに従ってAとBを切り替える
- Multiply：2つの条件が両方成立する場所を残す
- Bump：マスクを疑似的な段差として使う
- Principled BSDF：加工済みの情報を表面としてまとめる

実制作では、必要な構成をAIに相談しながら作り、こちらは「どの模様を増減したいか」「錆をどこへ限定したいか」「光沢をどうしたいか」を判断して数値を調整できればよい。

AIに全部任せて意味を見ないのではなく、完成した構成を読んで意図どおりか確かめられることが、今回の学習の価値だと思う。

## 振り返り

Day 13では、Day 12の白黒Noiseが単なる色ムラではなく、素材を切り替える共通の制御情報になることを体験した。

特に大きかったのは、色・Metallic・Roughness・Bumpが同じマスクを共有すると、表面の性質が同じ場所で一斉に変わると理解できたこと。そしてMultiplyを使えば、「剥がれていて、かつ錆候補でもある」という2条件を表現できた。

複雑さは一気に増したが、個々のノードではなく「マスクを作る」「素材を切り替える」「条件を重ねる」というまとまりで見ると、情報の流れは追える。

## 次回

次回は新しいノードを大量に増やさず、今回のマスク構成を読み返すところから始める。そのうえで、完成した部屋を魅力的に見せるカメラ・ライティング・演出のいずれかへ進み、マテリアル以外の表現も育てていく。
