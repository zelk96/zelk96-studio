# Blender学習 Day 10：UV展開とPBRテクスチャで机と床に木の質感を付ける

UVグリッドとシームで展開の基本を学び、Diffuse・Roughness・Normalを使ったPBR木材を机の天板と床へ適用しました。

<p class="post-meta">2026.08.22 · 黒暁</p>

## はじめに

Blender学習10日目。これまで単色のマテリアルで仕上げていた室内シーンに、初めて画像テクスチャを使った。

今回の中心はUV展開。立体の表面を平面へ開き、画像のどの部分をモデルのどこへ貼るかを決める仕組みを学んだ。練習用の箱でUVの歪みとシームを確認したあと、実際の木材テクスチャを机の天板と床へ適用した。

最終的にはDiffuse、Roughness、Normalの3種類を組み合わせたPBRマテリアルまで作成。単色だった部屋に木目と細かな凹凸が加わり、見た目が大きく変わった1日になった。

![木目の天板とフローリングを追加したDay 10の室内]({{ '/images/blender_day10_development_log/Day10_FinalRender.webp' | relative_url }})

## 今回の目標

- UVが何を決める仕組みなのか理解する
- UVグリッドでテクスチャの歪みを確認する
- シームを自分で設定して箱を展開する
- UVアイランドの大きさと配置を整える
- Diffuse、Roughness、Normalを使ったPBRマテリアルを作る
- 机の天板と床へ実際の木材テクスチャを適用する

## UVは立体と画像を対応させる設計図

最初に練習用の直方体 `UV_Practice_Cube` を作り、UV編集ワークスペースを開いた。

UVエディターに表示される展開図は、立体の表面を切り開いて平面へ置いたもの。画像の横方向をU、縦方向をVとして扱い、モデルの各面が画像上のどこを参照するかを決める。

今回は `U` →「キューブ投影」で箱型のモデルを自動展開し、1024×1024の生成画像 `UV_Checker` を作った。画像テクスチャノードからプリンシプルBSDFのベースカラーへ接続すると、モデル全体にチェック模様が表示された。

![UVグリッドを画像テクスチャとして接続した練習用の箱]({{ '/images/blender_day10_development_log/uv-checker-material.webp' | relative_url }})

チェック模様が正方形で、各面の細かさも揃っていれば、UVは大きく歪んでいない。完成用テクスチャを貼る前に、UVグリッドを定規として使えることが分かった。

## UVを縮め、意図的に歪みを作る

UVとモデルの関係を確認するため、手前の面だけを選び、UVエディターで `S` → `X` → `0.5` と横方向へ縮小した。

![一つの面だけUVを縮めて模様を横へ引き伸ばした状態]({{ '/images/blender_day10_development_log/uv-distortion-test.webp' | relative_url }})

モデルの形は変わっていないが、選んだ面だけチェック模様が大きな横長になった。画像の狭い範囲を広い面へ引き伸ばしたためで、ゲーム内の壁などで見かける「模様だけが伸びている」状態を再現できた。

この確認から、UVを作る前にはモデルの大まかな形とサイズを決め、`Ctrl + A` →「スケール」で変形倍率を適用しておくことが重要だと分かった。

## シームを指定して箱を手動展開する

自動のキューブ投影だけでなく、自分で切れ目を決めるシームも試した。

最初に既存のシームをすべてクリアし、上面を囲む4辺と底面を囲む4辺を選択して、`Ctrl + E` →「シームをマーク」を実行した。さらに側面4枚の輪を開くため、縦方向の辺を1本だけシームにした。

![上面を囲む辺へ手動でシームを付けた状態]({{ '/images/blender_day10_development_log/manual-seams.webp' | relative_url }})

Blender 5.2では `U` メニューから「等角で展開」を選択。箱のような直線的で単純な形に向いた方式で、指定した赤いシームに沿ってUVが作り直された。

![手動で付けたシームに沿って等角展開したUV]({{ '/images/blender_day10_development_log/conformal-unwrap.webp' | relative_url }})

シームは、紙工作を平面へ戻すときの切れ目に近い。上面と底面を分離し、側面の輪へ縦の切れ目を入れることで、閉じた立体を無理なく平面へ開けた。

## UVアイランドの大きさと配置を整える

展開後は、UVメニューから次の2つを実行した。

| 操作 | 役割 |
| --- | --- |
| アイランドの大きさを平均化 | モデル上の面積に対するテクスチャ密度を揃える |
| アイランドを梱包 | 画像の正方形内へUVを効率よく配置する |

梱包時の余白は `0.02` に設定した。UVアイランド同士に隙間を作り、隣の色がにじむのを防ぐためだ。

練習用のチェック模様では回転を許可したため、梱包後の模様が斜めになった。歪みではなく、Blenderが空きスペースを減らすためUVアイランドを回転させた結果だった。

木目や文字のように方向が重要な画像では、梱包設定の「回転」をOFFにするか、梱包後に `R` で向きを整える必要がある。

## 机の天板へPBR木材を適用する

練習後は、Day 9の室内にある `Desk_Top` へ木材テクスチャを適用した。

天板は薄い箱型なので、スケールを適用してからキューブ投影を使用。UVアイランドの大きさを平均化し、回転OFF・余白0.02で梱包した。

素材にはPoly Havenの[Wood Table](https://polyhaven.com/a/wood_table)を使用した。1KのJPGをダウンロードし、天板専用マテリアル `MAT_DeskTop_Wood` を作成した。

もとの `Wood` マテリアルは5個のオブジェクトで共有されていたため、利用数を示す「5」をクリックして単独化している。この操作をせずにノードを変更すると、机の脚など共有先まで一緒に木目へ変わるところだった。

## Diffuse・Roughness・Normalを接続する

今回は3種類の画像を使用した。

| マップ | 接続先 | 色空間 | 役割 |
| --- | --- | --- | --- |
| Diffuse | ベースカラー | sRGB | 木材の色と模様 |
| Roughness | 粗さ | 非カラー | 場所ごとの光沢とざらつき |
| Normal GL | ノーマルマップを経由してノーマル | 非カラー | 木目や傷の細かな凹凸 |

Normal画像は直接プリンシプルBSDFへつながず、「ノーマルマップ」ノードを間に置いた。天板では強さを `0.35` に設定し、凹凸が過剰にならないよう調整した。

![Diffuse・Roughness・Normalを接続した天板のPBRマテリアル]({{ '/images/blender_day10_development_log/desk-pbr-nodes.webp' | relative_url }})

形状自体は平らなままだが、Normalマップが面の向きを疑似的に変化させ、木目や傷が光を受けたときに立体的に見えるようになった。

![木目のPBRマテリアルを適用した机のレンダー]({{ '/images/blender_day10_development_log/desk-texture-render.webp' | relative_url }})

## 床でも同じ手順を復習する

余力があったため、同じ流れを `Room_Floor` でも繰り返した。

床も薄い箱型なので、キューブ投影、アイランドの大きさを平均化、回転OFFでの梱包を使用。素材にはPoly Havenの[Old Wooden Floor 01](https://polyhaven.com/a/old_wooden_floor_01)を選んだ。

床専用の `MAT_Floor_Wood` を作り、Diffuse、Roughness、Normal GLを接続。広い面で凹凸が強く出すぎないよう、Normalの強さは `0.25` にした。

![3種類の画像を接続して作った床のPBRマテリアル]({{ '/images/blender_day10_development_log/floor-pbr-nodes.webp' | relative_url }})

床板は部屋の奥行き方向へ伸びる向きになり、視線が自然に室内の奥へ進む配置になった。単色だった床が明るい木材へ変わり、部屋全体の印象も大きく変化した。

## 今日使った主な操作・機能

| 操作・機能 | 内容 |
| --- | --- |
| UV編集 | 立体の面と画像上の範囲を対応させる |
| UVグリッド | 模様の伸びや面ごとの密度差を確認する |
| `U` → キューブ投影 | 箱型モデルを6方向から自動投影する |
| `Ctrl + E` → シームをマーク | 手動展開で切り開く辺を指定する |
| `U` → 等角で展開 | 箱など直線的な形をシームに沿って展開する |
| アイランドの大きさを平均化 | 面ごとのテクスチャ密度を揃える |
| アイランドを梱包 | UVを画像内へ効率よく配置する |
| 画像テクスチャ | 外部画像をマテリアルへ読み込む |
| 非カラー | RoughnessやNormalを色ではなくデータとして扱う |
| ノーマルマップ | 凹凸画像をシェーダーが利用できる情報へ変換する |
| リソースをパック | 外部画像をBlendファイル内へ埋め込む |

## 振り返り

Day 10では、モデルの形を作る工程から一歩進み、表面へ画像の情報を割り当てるUVを初めて扱った。

キューブ投影を使う箱型のUVは、机の天板と床で同じ手順を繰り返したことでかなり慣れた。`スケール適用 → キューブ投影 → 大きさを平均化 → 梱包` という流れは、今後も単純な四角形のオブジェクトへ使えそうだ。

一方、シームは立体ごとに「どこを切れば平面へ開けるか」を考える必要があり、まだ自信が十分ではない。今回は箱の上面・底面・縦辺で基本を確認できたので、円柱や曲面を含む別の形でも何度も使いながら慣れていきたい。

最も大きな変化は、DiffuseだけでなくRoughnessとNormalまで接続したことだった。単色マテリアルでは表現できなかった傷、光沢、木目の凹凸が加わり、天板と床だけでも室内の説得力が大きく上がった。

## 次回

一日置いて同じ操作を自力で再現し、記憶を定着させる。まずはドアなど単純な箱型のオブジェクトへUVとPBR素材を追加し、その後は円柱や曲面のあるモデルでシームの練習を続ける。
