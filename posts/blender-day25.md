# Blender学習25日目｜首と頭を追加して全身リグを完成させる

今日は、昨日までに作った胴体・両腕・両脚のリグへ首と頭を追加した。

首と頭のメッシュをボーンへ親子付けし、それぞれに回転制限を設定した。さらに顔の正面を示すマーカーを追加し、向きや回転方向を確認しやすくした。

最後の全身動作テストでは、左脚の一部メッシュがボーンへ追従していない問題も発見した。親子付けを修正し、頭から足先までを`SH_Root`からまとめて動かせる状態に仕上げた。

## 首と頭のボーンを追加

最初に`EL_Armature`の編集モードで、`SH_Spine`のテールからZ方向へ新しいボーンを押し出した。

1本目を首用の`SH_Neck`、そのテールから続けて押し出した2本目を頭用の`SH_Head`と命名した。

- `SH_Neck`：長さ約`0.5m`
- `SH_Head`：長さ`1m`

![背骨の上へ首と頭のボーンを追加](/zelk96-studio/images/day25/01.png)

完成した上半身中央の階層は次のようになった。

```text
SH_Spine
└─ SH_Neck
   └─ SH_Head
```

背骨・首・頭を接続して作ったため、親を動かすとその先の子ボーンも追従する構造になっている。

## 首と頭の簡易メッシュを作成

続いて、首には円柱、頭にはUV球を使って簡易メッシュを作成した。

編集モードで対象ボーン全体を選択し、`Shift + S`の「カーソル → 選択物」で3Dカーソルをボーン中央へ移動。その位置へメッシュを追加して、ボーンを包む大きさに調整した。

- 首メッシュ：`SH_NeckMesh`
- 頭メッシュ：`SH_HeadMesh`

![首の円柱と頭のUV球を配置した状態](/zelk96-studio/images/day25/02.png)

形を調整した後は、両方ともスケールを適用した。

## メッシュをボーン相対で親子付け

首と頭は今回も硬いパーツとして扱うため、ウェイトではなく「ボーン相対」で親子付けした。

| メッシュ | 親ボーン |
| --- | --- |
| `SH_NeckMesh` | `SH_Neck` |
| `SH_HeadMesh` | `SH_Head` |

動作確認では、それぞれ次のように連動した。

- `SH_Head`を回すと頭だけが動く
- `SH_Neck`を回すと首と頭が一緒に動く
- `SH_Spine`を回すと胴体・両腕・首・頭がまとめて動く

![背骨の回転へ上半身と頭が追従することを確認](/zelk96-studio/images/day25/03.png)

階層の上にある骨ほど、広い範囲のパーツをまとめて操作できることを改めて確認できた。

## 首に回転制限を追加

首が人体では不可能な角度まで回らないよう、`SH_Neck`へ「回転制限」コンストレイントを追加した。

オーナー空間を「ローカル空間」に設定し、「トランスフォームに影響」を有効化した。各軸の範囲は次のとおり。

| 軸 | 最小 | 最大 | 主な動き |
| --- | ---: | ---: | --- |
| X | `-30°` | `30°` | 前後へ倒す |
| Y | `-60°` | `60°` | 左右を向く |
| Z | `-30°` | `30°` | 横へ傾ける |

![SH_Neckへローカル空間の回転制限を設定](/zelk96-studio/images/day25/04.png)

`R → X → X`、`R → Y → Y`、`R → Z → Z`で各ローカル軸を試したところ、範囲を超える角度を入力しても設定した境界で停止した。

首は肘や膝のような一方向の関節ではないため、3軸すべてに可動範囲を持たせた。

## 顔の正面を示すマーカーを追加

頭が真球のままでは、Y軸を中心に回しても現在どちらを向いているか分かりにくい。

そこでDay22の胸マーカーと同じ考え方で、小さなUV球をキャラクターの正面である`-Y`側へ配置し、`SH_FaceMarker`と命名した。

![頭の正面へSH_FaceMarkerを追加](/zelk96-studio/images/day25/05.png)

`SH_FaceMarker`は`SH_Head`へボーン相対で親子付けした。頭をローカルY軸へ120度回すとマーカーも頭の横へ移動し、正しく追従していることを確認できた。

![頭の回転へ顔マーカーが追従する状態](/zelk96-studio/images/day25/06.png)

胸と顔の両方に正面の目印ができたため、胴体と頭がそれぞれどちらを向いているか判断しやすくなった。

## 頭にも回転制限を追加

確認時点では`SH_Head`が120度まで自由に回転できたため、頭側にも「回転制限」を追加した。

首と同じくオーナー空間は「ローカル空間」、「トランスフォームに影響」を有効化した。首より狭い次の範囲へ設定した。

| 軸 | 最小 | 最大 |
| --- | ---: | ---: |
| X | `-25°` | `25°` |
| Y | `-45°` | `45°` |
| Z | `-20°` | `20°` |

![SH_Headへ首より狭い回転制限を設定](/zelk96-studio/images/day25/07.png)

再びローカルY軸へ120度を入力すると、今度は45度で停止した。

首全体の大きな動きを`SH_Neck`、その先にある頭の細かな調整を`SH_Head`へ分担させる構造になった。

## 全身テストで脚の不具合を発見

頭部の完成後、腰・腕・脚・首・頭を組み合わせた全身ポーズを試した。

ところが、左足と左すねのメッシュがボーンへ追従せず、元の場所へ残る問題が見つかった。

![全身テストで左脚のメッシュが残った状態](/zelk96-studio/images/day25/08.png)

ボーン階層そのものは動いていたため、原因はメッシュ側の親子付けだった。

一度「親子関係をクリア（トランスフォームを維持）」を実行し、次の組み合わせで「ボーン相対」の親子付けをやり直した。

| メッシュ | 親ボーン |
| --- | --- |
| `SH_FootMesh.L` | `SH_Foot.L` |
| `SH_ShinMesh.L` | `SH_Shin.L` |

修正後は、`SH_Shin.L`を曲げると左すねと足が一緒に動くようになった。

![左すねと足が膝の動きへ追従する状態](/zelk96-studio/images/day25/09.png)

さらに`SH_Thigh.L`を動かし、太もも・すね・足までが階層どおりに連動することも確認した。

![左太ももから足先までの追従確認](/zelk96-studio/images/day25/10.png)

完成後の全身テストは、個別作業では見つけにくい設定漏れを発見するためにも重要だと分かった。

## 腰を曲げるボーンを整理

全身ポーズを作る途中では、`SH_Pelvis`を回しても腰が曲がって見えないことにも気づいた。

`SH_Pelvis`は背骨と両脚の共通の親なので、回転させると上半身と脚がまとめて動く。骨盤に対して上半身だけを傾け、腰の角度を作る役割は`SH_Spine`が担当する。

- `SH_Pelvis`：上半身と両脚の土台となる骨盤
- `SH_Spine`：骨盤に対して上半身を曲げる背骨

`SH_Spine`をローカルX軸へ20度回すと、骨盤と両脚を残したまま、胴体・両腕・首・頭だけが傾いた。

![SH_Spineを回して腰から上半身を曲げた状態](/zelk96-studio/images/day25/11.png)

同じ「身体を傾ける」操作でも、どの階層のボーンを選ぶかによって動く範囲が変わる。

## ルートから全身の追従を確認

最後に`SH_Root`を上へ1m移動し、Z軸へ20度回転させた。

頭・顔マーカー・首・胴体・骨盤・両腕・両脚・足先までが、相対的な位置を保ったまま一緒に移動・回転した。

![SH_Rootの操作へ完成した全身が追従](/zelk96-studio/images/day25/12.png)

確認後は`Alt + G`と`Alt + R`で初期姿勢へ戻した。

## 現在のボーン階層

今日の作業を終えた時点で、ボーンの階層は次のようになった。

```text
SH_Root
└─ SH_Pelvis
   ├─ SH_Spine
   │  ├─ SH_Clavicle.L
   │  │  └─ WP_UpperArm.L
   │  │     └─ WP_Forearm.L
   │  ├─ SH_Clavicle.R
   │  │  └─ WP_UpperArm.R
   │  │     └─ WP_Forearm.R
   │  └─ SH_Neck
   │     └─ SH_Head
   ├─ SH_Thigh.L
   │  └─ SH_Shin.L
   │     └─ SH_Foot.L
   └─ SH_Thigh.R
      └─ SH_Shin.R
         └─ SH_Foot.R
```

`SH_Root`を最上位として、骨盤から上半身と両脚へ分かれ、背骨から両腕と頭部へ枝分かれする全身リグになった。

## 今日の振り返り

今日は首と頭を追加し、簡易人体の主要な部位を一通りそろえることができた。

首と頭はどちらも多方向へ動くが、同じ範囲で自由に回すのではなく、首を広め、頭を狭めに制限して動きを分担させた。顔マーカーを付けたことで、球体だけでは分からなかった頭の向きも明確になった。

また、全身ポーズを試したことで左足と左すねの親子付け不備を発見し、その場で修正できた。個々のパーツが動くだけでなく、親から子までを組み合わせて確認することがリグの完成には欠かせない。

`SH_Pelvis`と`SH_Spine`の役割の違いも、実際に動かして理解できた。ボーン名だけを覚えるのではなく、階層のどこにあり、どの範囲を動かす骨なのかを見ることが重要だと分かった一日だった。
