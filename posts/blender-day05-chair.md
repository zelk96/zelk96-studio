# Blender学習 Day 5：ミラーモディファイアーで木製チェアを作る

ミラーモディファイアーを使い、1本の脚から4本を生成。座面・脚・背柱・背もたれから木製チェアを制作しました。

<p class="post-meta">2026.08.17 · 黒暁</p>

## はじめに

Blender学習5日目。

Day 1の机、Day 2のマグカップ、Day 3のデスクライト、Day 4の本を引き継ぎ、今回は机に合わせた木製チェアを制作した。

座面・脚・背柱・背もたれというシンプルな構成だが、今回の主役は**ミラーモディファイアー**。脚を1本ずつ複製して位置合わせするのではなく、座面を基準に1本から4本を生成する方法を学んだ。

![Day 5の完成レンダリング]({{ '/images/blender_day05_development_log/Day05_Chair_Render.png' | relative_url }})

## 今回の目標

- 座面・脚・背柱・背もたれから椅子を組み立てる
- ミラーモディファイアーで1本の脚から4本を生成する
- 別オブジェクトをミラーの基準点として使う
- 必要な方向だけミラーして背柱を2本作る
- 既存マテリアルを一覧から再利用する
- 椅子のパーツを親子関係でまとめる
- カメラの見え方と実際の配置を切り分けて考える

## 座面を作る

立方体を追加し、X・Y方向へ広げ、Z方向へ薄くして `Chair_Seat` を作成した。机の手前へ移動し、正面・真上の両方から高さと中心を確認した。

スケールを適用してから、幅 `0.08m`、セグメント `3` でベベル。角をしっかり丸め、机よりも少し柔らかな印象の座面にした。

![ベベルを付けた座面]({{ '/images/blender_day05_development_log/seat-beveled.png' | relative_url }})

ベベルは前日までの復習でも使っていたため、今回は操作に迷わず進められた。ショートカットを覚えるだけでなく、どの程度の丸みが形に合うかを見ながら調整する段階へ少しずつ進めている。

## 1本の脚から4本を作る

座面の中心にある3Dカーソルへ立方体を追加し、細長く変形して `Chair_Leg` を作成。座面の角の下へ1本だけ配置した。

ここで脚にミラーモディファイアーを追加し、ミラーオブジェクトへ `Chair_Seat` を指定。X軸とY軸を有効にすると、座面の原点を基準に脚が左右・前後へ反転され、合計4本になった。

![1本から4本へ生成した椅子の脚]({{ '/images/blender_day05_development_log/leg-mirror-four.png' | relative_url }})

これなら4本を個別にコピーして位置合わせする必要がない。元の脚1本を編集すれば、ほかの3本にも同じ変更が反映される。スケール適用後に幅 `0.03m`、セグメント `3` のベベルを加えると、4本すべてが同時に丸くなった。

今回いちばん「便利だ」と実感した機能だった。

## 背柱の位置を直す

次に背もたれを支える `Chair_BackPost` を1本作った。最初はY方向の符号を取り違え、背柱が机に近い側へ立ってしまった。

椅子の向きと机との位置関係を確認し、`G` → `Y` で反対側へ移動。数値ではY座標を `+0.58` 付近から `-0.58` 付近へ変更し、座る人の背中側へ直した。

![机側から反対側へ修正した背柱]({{ '/images/blender_day05_development_log/back-post-corrected.png' | relative_url }})

正面だけを見ていると前後を取り違えやすい。斜め視点へ回り込み、「机に向かって座るなら背もたれはどちら側か」を立体的に確認するのが確実だった。

## 背柱はX方向だけミラーする

背柱にもミラーモディファイアーを追加し、基準には座面を指定した。今回は前後へ増やす必要がないため、X軸だけを有効にして左右2本にした。

![X方向だけミラーした2本の背柱]({{ '/images/blender_day05_development_log/back-post-mirror.png' | relative_url }})

脚ではX・Y、背柱ではXだけ。同じ機能でも、必要な対称方向に合わせて軸を選ぶことが大切だと分かった。

背柱もスケールを適用し、幅 `0.025m`、セグメント `3` でベベルした。

## 背もたれを追加する

座面中央の3Dカーソル位置へ新しい立方体を追加し、横長で薄い板へ変形。Y方向へ背柱側、Z方向へ上げて `Chair_Backrest` とした。

追加位置は選択中のオブジェクトではなく、3Dカーソルで決まる。途中で「座面を選択しておく必要があるのか」と疑問になったが、今回のようにカーソルが座面中央へ残っていれば、どのオブジェクトを選択していても同じ場所から追加できる。

スケールを適用し、幅 `0.06m`、セグメント `3` でベベルして背もたれを完成させた。

![背もたれを追加した椅子]({{ '/images/blender_day05_development_log/backrest-complete.png' | relative_url }})

## マテリアルを再利用する

座面へ暗い赤茶色の `Chair_Wood` を作成し、粗さを `0.45` に設定した。脚・背柱・背もたれには新しいマテリアルを作らず、保存済みのマテリアル一覧から `Chair_Wood` を選択した。

![全パーツへ木材マテリアルを設定]({{ '/images/blender_day05_development_log/chair-material.png' | relative_url }})

Day 4で学んだマテリアル一覧からの再利用も、今回は手順を細かく確認せず進められた。反復した操作が少しずつ定着してきている。

## 椅子のパーツを親子関係でまとめる

完成した4種類のパーツは、座面を親としてペアレントした。

- `Chair_Seat`（親）
  - `Chair_Leg`（子・ミラーで4本）
  - `Chair_BackPost`（子・ミラーで2本）
  - `Chair_Backrest`（子）

アウトライナーで階層を確認し、座面を移動・回転すれば椅子全体が一緒に動く状態にした。

![アウトライナーで確認した椅子の親子関係]({{ '/images/blender_day05_development_log/chair-parenting.png' | relative_url }})

Day 4の本とタイトルでは親子を逆にしてしまったことがあったため、今回は選択結果だけで判断せず、設定後の階層まで確認した。

## 配置とカメラ構図

椅子は机の手前中央へ配置した。前日と同じ斜め上のカメラ構図では椅子が左寄りに見えたが、真上や正面から確認すると、実際の位置は机のほぼ中央だった。

![前日と同じカメラ構図で確認した椅子]({{ '/images/blender_day05_development_log/camera-composition.png' | relative_url }})

透視投影では、画面上の見た目とワールド上の位置が一致しないことがある。今回は見た目だけを理由に位置をずらさず、複数視点で配置を確認して中央のままにした。

最終レンダリングでは、椅子は机の影に入るため天板より暗く見える。シーンの照明による自然な差として残し、これまで作った机・本・マグカップ・ライトと一緒に1つの学習机らしい場面へまとめた。

## 今日使った主な操作・機能

| 操作・機能 | 内容 |
| --- | --- |
| `Shift + S` | 3Dカーソルや選択物の位置をスナップする |
| `Shift + A` | 3Dカーソル位置へ新しいオブジェクトを追加する |
| `Ctrl + A` → スケール | 現在の大きさを基準値として適用する |
| `Ctrl + B` | 選択した辺をベベルする |
| ミラーモディファイアー | 元形状を指定軸へ反転して複製する |
| ミラーオブジェクト | 別オブジェクトの原点を反転の基準にする |
| マテリアル一覧 | 作成済みマテリアルを別パーツへ再利用する |
| `Ctrl + P` | 複数パーツへ親子関係を設定する |
| アウトライナー | 親子構造や選択状態を確認する |
| `F12` | レンダリングする |

## 振り返り

Day 5では、基本形を組み合わせる椅子制作を通して、ミラーモディファイアーの便利さを体験した。とくに「1本作れば4本が揃う」という非破壊的な作り方は、これまでの複製と手動配置から大きく進んだ感覚があった。

一方で、背柱を机側へ置いてしまう失敗もあった。座標の数字だけを見るのではなく、完成時の向きや用途を考え、視点を変えて確認することが重要だった。

ベベル、3Dカーソル、オブジェクト追加、マテリアル設定といった既習操作は、自分で意味を説明しながら使えるようになってきた。覚えた部分の説明を省略し、新しい機能へ学習時間を使えるようになったのも大きな進歩だった。
